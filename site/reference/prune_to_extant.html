Description

Drops tips that did not survive to the present (i.e. tips whose root-to-tip distance is shorter than the maximum, within a small numerical tolerance).

Usage

prune_to_extant(phy, tol = 1e-08)

Arguments

phy

A phylo object, possibly containing extinct lineages.

tol

Tolerance for deciding whether a tip is at the present. Default 1e-8.

Value

A phylo object with only extant tips retained.
