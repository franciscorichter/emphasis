Description

One application of the sweep the thinning sampler carries forward: it rewrites tip_start, focal_tip_start and pd on every node from the event list alone. With parent_tip_start supplied the sweep is driven by the observed topology, exactly as the closing pass of augment_trees is: the k-th observed node is given the k-th entry as the tip start of the lineage that splits there, and the tree is read under the topology convention. With it empty the tree is replayed as it stands, under the convention its clade column records and with the focal_tip_start it already carries as the match key.

Usage

eval_pendant_sweep(
  tree,
  parent_tip_start = as.numeric(c()),
  parent_id = as.integer(c())
)

Arguments

tree

One augmented-tree data frame from augment_trees.

parent_tip_start

The tip starts the augmentation was driven by, or numeric(0) to replay the tree as it stands.

Details

An augmented tree returned by augment_trees is a fixed point of the first form: the state the sampler carried is the tree that comes back.

Value

The same data frame with tip_start, focal_tip_start and pd rewritten by the sweep.
