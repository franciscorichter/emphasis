Description

E-step and M-step of one iteration are a single em_cpp() call: the augmented trees are drawn by the thinning sampler, up to maxN attempts per E-step.

Usage

.mcem_dynamic_fresh(
  brts,
  pars,
  sample_size,
  maxN,
  max_missing,
  lower_bound,
  upper_bound,
  max_iter,
  xtol,
  tol = 0.01,
  patience = 3L,
  num_threads,
  verbose = FALSE,
  conditional = NULL,
  model = c(0L, 0L, 0L),
  link = 0L,
  max_time = NULL,
  rho = 1,
  rel_floor = 0.01,
  stop_rule = c("rel_change", "mc_error"),
  mc_batches = 5L,
  mc_z = 1,
  mc_grow = 1.5,
  max_draws = NULL
)

Details

Stopping rule, the same statistic .mcem_bdi uses. With theta_k the M-step output of iteration k,

\[\delta_k = \max_j |\theta_k[j] - \theta_{k-1}[j]| / \max(|\theta_{k-1}[j]|, \epsilon)\]

and the run stops as "converged" once \(\delta_k < tol\) for patience consecutive iterations. The search box does not enter, so the same fit stops at the same point whatever bounds the user passes. The floor \(\epsilon\) comes from .rel_floor(brts, link, rel_floor) and carries the units of the parameters (rel_floor / crown_age for the rate-valued links, rel_floor for the log-rates of the exponential link), so the statistic is unchanged when the tree and the rates are expressed in another unit of time. An iteration whose M-step returned its starting point unchanged carries no information about stability and resets the streak (trace column m_moved). The trace also records the absolute step abs_step and drift, the same relative displacement measured over the last patience iterations.

Trace. Row k of mcem pairs theta_k with the E-step value fhat(theta_{k-1}) it was computed from, and with the rejection counters of that E-step. The likelihood of the returned point is a separate E-step at the final iterate, appended as the last row (m_step = FALSE, step columns NA); only that row is evaluated at pars, and it is not counted in iterations. It is attempted whenever at least one iteration succeeded, including after a "e_step_failure" or "time_budget" stop, and may itself fail, in which case there is no such row and loglik, loglik_var and final_IS report nothing rather than the previous iterate's values.

Rejection columns. rejected_errors (unhandled exception), rejected_overruns (max_missing exceeded), rejected_lambda (max_lambda exceeded) and rejected_nonfinite (log weight +Inf or NaN) are the four disjoint ways a draw is discarded; n_rejected is their sum, the quantity final_IS$n_rejected reports, and rejected is that same total under the name the BDI trace uses. rejected_zero_weights is counted apart: those draws completed, have weight zero and stay in the fhat denominator.

Value

A list: mcem (trace, one row per completed iteration plus the final E-step), pars, iterations (number of completed E+M iterations, not loop passes and not nrow(mcem)), n_failed (E-step failures over the whole run), stop_reason, final_estep (did the final E-step at pars succeed), maxN (the ratcheted attempt cap: doubled on every E-step failure up to 50000, never reset after a success), loglik (fhat at pars, NA when the final E-step failed), loglik_var, final_IS.
