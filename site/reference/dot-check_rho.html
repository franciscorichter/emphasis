Description

rho is the fraction of extant species present in the tree, so it lives in (0, 1]. The C++ layer (model.hpp) replaces any value outside that range by 1 and reports nothing, so a call made with rho = 80 or rho = -1 returns a complete-sampling fit under the label the user asked for (audit finding H79). Every R entry point that accepts rho checks it here first.

Usage

.check_rho(rho, arg = "control$rho")

Arguments

rho

The value supplied by the caller.

arg

Name to quote in the error message.

Value

rho as a length-1 double.
