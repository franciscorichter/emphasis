Description

The fair-proportion routine the likelihood and the simulator share (inst/include/ed_covariate.hpp), exposed so that it can be checked against an independent computation on an ape tree.

Usage

ed_fair_proportion(parent, birth, alive, t)

Arguments

parent

Integer vector: for each lineage, the (1-based) index of the lineage it split from, or 0 for a crown lineage.

birth

Numeric vector: each lineage's birth time (forward).

alive

Logical vector: whether each lineage is alive on the segment being evaluated.

t

The evaluation time.

Value

A data frame with one row per lineage: c and ts such that ED(u) = c + (u - ts) for u in the segment (NA for a lineage not alive), ed the value at t, and n_desc the alive lineages in its subtree.
