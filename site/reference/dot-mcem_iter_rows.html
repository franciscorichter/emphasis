Description

Both drivers append the final E-step at the parameters they return as a trace row. That row is not an iteration: it carries no M-step and no step metrics. .mcem_bdi flags it m_step = FALSE and .mcem_dynamic_fresh flags it final_estep = TRUE; both flags are read here, so that anything counting or plotting the trace reports K rows for a K-iteration fit.

Usage

.mcem_iter_rows(mcem_df)

Arguments

mcem_df

An MCEM trace data frame, or NULL.

Value

A logical vector over the rows of mcem_df.
