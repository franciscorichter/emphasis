Description

Drop-in replacement for .mcem_dynamic_fresh(). Uses BDI exact sampling for the E-step and m_cpp() for the M-step.

Usage

.mcem_bdi(
  brts,
  pars,
  sample_size,
  max_missing,
  lower_bound,
  upper_bound,
  max_iter,
  xtol,
  tol = 0.01,
  patience,
  num_threads,
  verbose = FALSE,
  conditional = NULL,
  model = c(0L, 0L, 0L),
  link = 0L,
  max_time = NULL,
  rho = 1,
  stop_rule = c("rel_change", "mc_error"),
  mc_batches = 5L,
  mc_z = 1,
  mc_grow = 1.5,
  max_draws = NULL,
  mesh = NULL,
  damping = "auto"
)

Details

Under CR: zero-variance IS, so every E-step gives the same fhat regardless of the augmented trees. Convergence depends only on the M-step.

Stopping rule. With theta_k the M-step output of iteration k,

\[\delta_k = \max_j |\theta_k[j] - \theta_{k-1}[j]| / \max(|\theta_{k-1}[j]|, \epsilon)\]

(.rel_change) with \(\epsilon\) from .rel_floor, and the run stops as "converged" once \(\delta_k < tol\) for patience consecutive iterations. The scale is the parameter itself, not the search box, so the same fit stops at the same point whatever bounds the user passes; the floor carries the units of the parameters, so it also stops at the same point when the tree is measured in another unit of time. An iteration whose M-step returned its starting point unchanged carries no information about stability and resets the streak. The trace also records the absolute step abs_step and drift, the same relative displacement measured over the last patience iterations: under pure Monte Carlo noise drift is of the order of sqrt(patience) steps, under a deterministic EM drift it is patience steps.

The reported likelihood is a separate E-step at the final iterate, so fhat, ESS, final_IS and loglik_var all describe pars; that E-step is the last row of mcem (m_step = FALSE, no step columns) and is not counted in iterations. When that E-step fails and the final iterate is not the last one whose E-step succeeded, pars falls back to that iterate and the E-step is run there: a theta the sampler cannot evaluate is not returned as an estimate.

Draw counts come from the E-step, which drops non-finite draws before returning: n_valid is the number of completed draws and the fhat denominator, num_trees the finite subset handed to the M-step, and n_nonfinite the difference. rejected and rejected_max_missing are the two rejection channels.

Eight E-step failures end the run with stop_reason = "e_step_failure" whether or not they are consecutive, so an M-step that keeps proposing an iterate the sampler cannot evaluate does not alternate to max_iter.

Value

A list: mcem (trace, one row per iteration plus the final E-step), pars, iterations (number of completed E+M iterations), stop_reason, loglik (fhat at pars, NA when the final E-step failed), loglik_var, final_IS, n_failed (E- or M-step failures).
