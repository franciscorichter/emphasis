Description

One row per lineage alive on each segment between consecutive events: the segment, the lineage (index and id), whether that lineage's event ends the segment (0 none, 1 speciation, 2 extinction), the segment's bounds, N, M, the lineage's pendant start (so D = (t - ts) - M) and its ED at the segment start (ED grows at slope one within the segment).

Usage

lineage_table_cpp(tree)

Arguments

tree

One augmented-tree data frame with the topology (ids).
