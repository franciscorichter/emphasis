Description

Uses optim (L-BFGS-B) to maximize the GAM-predicted log-likelihood surface.

Usage

find_MLE(gam_fit, lower_bound, upper_bound, start = NULL, par_names = NULL)

Arguments

gam_fit

A gam object returned by train_likelihood_GAM.

lower_bound

Numeric vector of lower bounds for each parameter.

upper_bound

Numeric vector of upper bounds for each parameter.

start

Optional numeric vector of starting values. If NULL, the grid point with the highest predicted value is used.

par_names

Character vector of parameter names matching the GAM predictors. If NULL, inferred from the GAM formula.

Value

A list with components:

pars

Named numeric vector of MLE estimates.

loglik

Predicted log-likelihood at the MLE.

convergence

Convergence code from optim (0 = success).

optim

Full optim output.
