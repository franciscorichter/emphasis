Description

Given a list of augmented trees (produced by augment_trees) and a parameter vector, computes for each tree:

  • logf[i] = log p(obs, z_i | theta) (model log-likelihood)

  • logg[i] = log q(z_i | obs, theta) (proposal log-probability)

Both are evaluated at the supplied pars, regardless of which parameters were used to simulate the trees. This is essential for shared-tree (Mode 2) evaluation where trees simulated at one particle are scored at another.

Usage

eval_logf(pars, trees, model = as.integer(c(0, 0, 0)), link = 0L, rho = 1)

Arguments

pars

Numeric vector of 8 model parameters.

trees

List of augmented-tree data frames (output of augment_trees).

model

Integer vector c(use_N, use_P, use_E).

link

Link function: 0 = linear, 1 = exponential.

Value

A named list:

logf

Numeric vector of log p(obs, z_i | theta).

logg

Numeric vector of log q(z_i | obs, theta).
