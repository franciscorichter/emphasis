Description

Selects the top disc_prop fraction of valid particles (elites) and fills the remaining slots with perturbed copies of elites. All particles (including elites) have their fhat reset to NA so they are re-evaluated at the next iteration, preventing "lucky particle" lock-in.

Usage

.resample_particles(
  pop,
  num_points,
  disc_prop,
  lower_bound,
  upper_bound,
  sd_vec,
  clear_cache = FALSE
)

Arguments

clear_cache

Logical; if TRUE, discard all tree/log_q caches.

Details

When clear_cache = FALSE (Mode 1), elite tree/log_q caches are carried forward. When clear_cache = TRUE (Mode 2), all caches are discarded so every particle simulates fresh trees at the next iteration. This prevents stale trees from unconverged early iterations from polluting the shared pool.

Value

Updated population list.
