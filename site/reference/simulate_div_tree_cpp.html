Description

Simulate a single phylogenetic tree under the general diversification model

Usage

simulate_div_tree_cpp(
  pars,
  model,
  max_t,
  max_N,
  max_tries,
  link = 0L,
  seed = 0L
)

Arguments

pars

Numeric vector of length 8: c(beta_0, beta_N, beta_M, beta_D, gamma_0, gamma_N, gamma_M, gamma_D). Inactive parameters (those not selected by model) should be set to 0.

model

Integer vector of length 3: c(use_N, use_P, use_E) (each 0 or 1).

max_t

Crown age (forward simulation end time).

max_N

Maximum number of lineages before simulation is declared too large.

max_tries

Maximum retries after extinction; an overflow is not retried.

link

Link function: 0 = linear (max(0,...)), 1 = exponential.

seed

Positive integer seeding the simulator. 0 (the default) draws one from R's generator, so set.seed() reaches the simulator whether or not a seed is passed. Note that max_tries retries continue the same stream: a retry is a fresh tree, not the same one again.

Value

A named list with Ltable (4-column numeric matrix in DDD format) and status (one of "done", "extinct", "too_large").
