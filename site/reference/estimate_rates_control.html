Description

Returns a list of default tuning parameters for estimate_rates. Override individual elements and pass the modified list via the control argument.

Shared parameters (all methods): lower_bound (required, no default), upper_bound (required, no default), verbose (default FALSE), max_missing (default 1e4), num_threads (default 1), rho (sampling fraction, a single number in \((0, 1]\); default 1 = complete sampling, and an out-of-range value is an error rather than being replaced by 1).

MCEM-specific: sampling (default "bdi", the birth-death-with-immigration sampler, which covers the cr and dd models on the linear and exponential links and cr on the gaussian link, at any rho in \((0, 1]\). Under constant rates it draws from the exact conditional distribution, so its log-weights are constant and its effective sample size is the number of draws; under diversity dependence it is a mean-field approximation and the weights vary. "dynamic_fresh" is the thinning sampler, used for a D- or M-dependent model, for dd on the gaussian link, and whenever it is asked for. A fallback is announced with a message naming the reason and the sampler that runs), num_trees (augmented trees per EM iteration, default 200; alias: sample_size), max_iter (iteration cap, default 200), maxN (max augmentation attempts per E-step, read by the thinning sampler only and ignored by BDI; under "dynamic_fresh" it must be at least num_trees; default NULL, and a non-finite value is treated as NULL, = max(2000, 10 * num_trees)), xtol (M-step optimiser tolerance, default 1e-3), tol (parameter-stability threshold: the largest relative parameter change \(\max_j |\theta_k[j] - \theta_{k-1}[j]| / \max(|\theta_{k-1}[j]|, c)\), where the floor \(c\) is tol / crown_age for the rate-valued links and tol for the log-rates of the exponential link, so that the statistic does not change with the unit of time; the search box does not enter; default 1e-2, so every coordinate must move by less than 1% of its own magnitude, patience times in a row; on a 12-tip CR tree at num_trees = 200 that statistic has median 0.02 and falls below 1e-2 in about a fifth of iterations, so runs at these defaults commonly end at max_iter), patience (consecutive stable iterations required, default 3).

CEM-specific: max_iter (default 20), num_particles (particles per iteration, default 50; alias: num_points), num_trees (trees per particle, default 1; alias: sample_size), sd_vec (NULL = (upper-lower)/4), maxN (default 10), disc_prop (default 0.5), tol (plateau threshold, default 1e-4), patience (default 5), bias_correct (default FALSE).

GAM-specific: grid_points (per-parameter resolution, default 20), sample_size (IS trees per grid point, default 200), maxN (NULL = auto), max_lambda (default 500), spline_type ("univariate" or "bivariate").

Usage

estimate_rates_control(method = c("mcem", "cem", "gam"), n_pars = 4)

Arguments

method

Which method's defaults to return: "mcem", "cem", or "gam".

n_pars

Number of parameters (used to set the default sd_vec for CEM when NULL).

Value

A named list of control parameters for the chosen method.
