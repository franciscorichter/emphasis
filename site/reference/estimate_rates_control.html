Description

Returns a list of default tuning parameters for estimate_rates. Override individual elements and pass the modified list via the control argument.

Usage

estimate_rates_control(method = c("mcem", "cem", "gam"), n_pars = 4)

Arguments

method

Which method's defaults to return: "mcem", "cem", or "gam".

n_pars

Number of parameters (used to set the default sd_vec for CEM when NULL).

Value

A named list of control parameters.

Shared parameters (both methods):

lower_bound

Numeric vector of lower parameter bounds. Length must be 2 + 2*sum(model). Required (no default).

upper_bound

Numeric vector of upper parameter bounds (same order). Required (no default).

verbose

Print progress messages. Default FALSE.

max_missing

Max extinct lineages per augmented tree. Trees that require more than this many extinct lineages are discarded. Default 1e4.

num_threads

Threads for parallel computation. Default 1.

rho

Sampling fraction: the proportion of extant species present in the tree, in (0, 1]. Default 1 (complete sampling). Values outside (0, 1] are an error. Under rho < 1 the augmentation inserts unsampled extant lineages as well as extinct ones; both samplers do so, and the choice of sampler does not depend on rho.

max_time

Wall-clock budget of the fit in seconds; NULL disables it. Default 3600. Under "mcem" the clock binds inside the E-step and the M-step, and the fit ends with stop_reason = "time_budget" and a clock note naming the step it cut. Both samplers stop drawing when it runs out, inside a draw as well as between draws, and the iteration in progress is discarded. The M-step's optimiser reads it before every evaluation of its objective; cut short, the iteration keeps the best point the optimiser had evaluated when that point improves on the current iterate, and is discarded otherwise. The E-step that evaluates the returned parameters then gets max_time again, and when it runs out its log-likelihood rests on the draws it made, so an MCEM fit returns within about twice max_time. Under "cem" and "gam" the clock is read between evaluations.

MCEM-specific parameters:

sampling

Sampling scheme: "bdi" (default), the birth-death-with-immigration sampler, which covers the cr and dd models on the linear and exponential links, at any rho in (0, 1]; or "dynamic_fresh", the thinning sampler, which covers every model, link and rho. Under constant rates the BDI proposal is the exact conditional distribution, so its weights are constant and its effective sample size is the number of draws; under diversity dependence and under ED it is a mean-field approximation and the weights vary. "bdi" falls back to "dynamic_fresh", with a message naming the reason, for a D- or M-dependent model.

damping

BDI only: under-relaxation of the mean-field sweep, which is a Picard iteration \(x \leftarrow F(x)\). Where its map expands the iteration diverges and a larger budget makes it worse: on a 416-tip tree at rates whose equilibrium is critical the residual is 305 after 20 sweeps and 329 after 200. A partial step, \(x \leftarrow (1-\omega)x + \omega F(x)\), contracts it. "auto" starts at \(\omega = 1\) and halves it whenever the residual grows; on that tree it converges in 40 sweeps, and where the map already contracts it is the plain iteration to the bit. A number in \((0, 1]\) fixes \(\omega\) instead; 1 is the plain iteration. "default" (the default) is "auto" at rho = 1 and \(\omega = 1/8\) at rho < 1: in experiment E10c a fixed 1/8 converged 0 of 192 units within the 20 sweeps at rho = 1 against 131 for "auto", at 1.4–3.3 times the E-step time and no gain in effective sample, and below rho = 1 it converged more (142 against 131 at rho = 0.2); an explicit "auto" or number is used as given. Relaxation below about \(1/20\) converges too slowly to be useful. It fixes the iteration and nothing else: at 416 tips the effective sample is 2.1 of 97 even with a converged mean field, because the proposal must invent some 600 missing lineages there (audit H108). Every E-step's mean field is in the trace (mf_converged, mf_delta, the final residual, mf_sweeps, mf_omega, the relaxation of the last sweep, and mf_budget); when some E-step relaxed the iteration below the full step or did not converge within its sweep budget, or the setting is not "auto", the fit's notes carry a mean_field entry with the resolved setting (and whether it is the default for the fit's rho), the sweeps, relaxation and residual of the last E-step and whether it converged, and print() shows it.

mesh

BDI only, and only where its Gillespie branch runs (any model but "cr"): the number of steps per crown age the frozen rates are re-evaluated on. NULL (default) leaves the step uncapped, which is a rate held over a whole waiting time. A mesh tightens the weights — on a 60-tip dd tree the standard deviation of the log-weight falls from 0.465 to 0.061 at 2000 steps per crown age, and the effective sample from 600 draws rises from 527 to 598 — and does not move the estimate (dev/mfc_mesh.R).

proposal

The thinning sampler's proposal for an ED model ("ed", "ned", ~ ED): "ed" (default) draws the missing births at the model's total speciation rate over the alive lineages, each at its own ED, and attaches a birth to a lineage in proportion to that lineage's rate; "meanfield" draws them at N * lambda(N, M) with the ED term at zero and attaches uniformly, as for every other model. The two are the same proposal at beta_ED = gamma_ED = 0. Ignored for a model without ED.

num_trees

Augmented trees per EM iteration. Default 200. Alias: sample_size.

xtol

Relative tolerance for the M-step optimiser. Default 1e-3.

max_iter

Maximum EM iterations. Default 200.

maxN

Total augmentation attempts per E-step (accepted plus rejected). Read by the thinning sampler only; the BDI sampler has no such cap and ignores it. Under "dynamic_fresh" it must be at least num_trees, and estimate_rates stops with an error otherwise. Increase for models with high rejection rates (e.g. D/DD with strongly negative covariate slope). Default NULL, and a non-finite value is treated as NULL, which sets max(2000, 10 * num_trees).

tol

Parameter-stability convergence threshold. MCEM is considered converged when the largest relative parameter change, \(\max_j |\theta_k[j] - \theta_{k-1}[j]| / \max(|\theta_{k-1}[j]|, c)\), is below tol for patience consecutive iterations. The bound box does not enter. The floor \(c\) carries the units of the parameters (see .rel_floor): tol / crown_age where they are rates (linear link) and tol where they are log-rates (exponential link), so the statistic does not change when the tree is expressed in another unit of time. Default 1e-2: every coordinate must move by less than 1% of its own magnitude, patience times in a row. The step the sampler itself produces sets whether that is reachable – on a 12-tip CR tree at num_trees = 200 the statistic has median 0.02 and falls below 1e-2 in about a fifth of iterations – so runs at these defaults commonly end at max_iter. Raising num_trees shrinks the Monte Carlo part of the step.

patience

Number of consecutive iterations with parameter change below tol required to declare convergence. Default 3.

CEM-specific parameters:

max_iter

Maximum CEM iterations (hard cap). Default 20.

num_particles

Particle population size (parameter vectors per iteration). Default 50. Alias: num_points.

sd_vec

Initial perturbation SDs. NULL (default) sets each to (upper - lower) / 4 at call time.

maxN

Max augmentation attempts per particle evaluation. Default 10.

num_trees

Augmented trees simulated per particle per iteration. Default 1. Alias: sample_size.

shared_trees

If FALSE (default), each particle is evaluated on its own simulated trees. If TRUE, trees are pooled across all particles and every particle's fhat is re-evaluated over the full pool (lower variance; bias correction not yet implemented).

disc_prop

Elite fraction retained per iteration (Cross-Entropy Method). Default 0.5.

bias_correct

Apply moment-based bias correction to the IS log-likelihood. Default FALSE.

num_trees

When > 1, bootstrap variance of the log-likelihood is computed automatically (B = 200 replicates) from the IS weights already drawn. Minimum recommendation: 5. loglik_var in the fit is NA when num_trees = 1.
