Description

Only evaluates particles with NA fhat. For each such particle \(\theta_i\), simulates sample_size trees from \(q(z \mid \text{obs}, \theta_i)\) and computes:

\[\hat{f}(\theta_i) = \log\text{mean}\exp(\text{logf}(z, \theta_i) - \log q(z, \theta_i))\]

Elite particles with cached fhat are skipped entirely. Their cached trees and log_q values are also stored for potential use by the shared evaluator if the mode is later switched.

Usage

.eval_independent(pop, input, num_threads)

Value

Named list: updated pop, rej_lambda and rej_overruns vectors (length = number of particles evaluated).
