Description

Returns a list with four parallel components of length num_points:

pars

Data frame of parameter vectors.

fhat

Numeric; NA = needs evaluation.

log_q

List; per-particle vector of log q(z | obs, theta) for cached trees. NULL = no trees cached.

trees

List; per-particle list of raw augmented-tree data frames (C++ format for loglikelihood()). NULL = not cached.

Usage

.init_population(num_points, lower_bound, upper_bound)
