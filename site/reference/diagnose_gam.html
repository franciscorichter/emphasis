Description

Produces diagnostic plots and returns summary statistics from a estimate_rates fit obtained with method = "gam".

Usage

diagnose_gam(x, plot = TRUE, true_pars = NULL)

Arguments

x

An emphasis_fit object from estimate_rates with method = "gam".

plot

Logical; if TRUE (default), produce diagnostic plots.

true_pars

Optional numeric vector of true parameter values (for simulation studies).

Surface coverage ($surface_summary)

Summary of the IS log-likelihood grid: total grid points, number with finite fhat, fhat range, and mean trees per grid point.

GAM quality ($gam_summary)

Key statistics from the fitted GAM: deviance explained, GCV score, and effective degrees of freedom.

MLE ($mle)

The MLE parameter estimates and predicted log-likelihood at the optimum.

Value

A list of class "gam_diagnostics" (invisibly) with components surface_summary, gam_summary, and mle.

Examples

## Not run: 
sim <- simulate_tree(c(0.5, 0.1), max_t = 5, model = "cr")
fit <- estimate_rates(sim, method = "gam", model = "cr",
  control = list(lower_bound = c(0, 0), upper_bound = c(2, 1)))
diagnose_gam(fit)

## End(Not run)
