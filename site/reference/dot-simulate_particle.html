Description

Calls augment_trees to sample sample_size augmented trees from the proposal \(q(z \mid \text{obs}, \theta)\).

Usage

.simulate_particle(
  brts,
  pars8,
  model_bin,
  link,
  sample_size,
  maxN,
  max_missing,
  max_lambda,
  num_threads,
  rho = 1
)

Details

Returns the raw augment_trees output: logf, logg, trees, and rejection counts for adaptive limit escalation.
