Description

Under the linear and gaussian links the parameters are rates, of dimension 1/time, and the only rate scale in the problem is the inverse crown age: the floor is rel_floor / crown_age, which rescales with the rates themselves. Under the exponential link the parameters are log-rates, where an absolute step already is a relative change of the rate, so the floor is rel_floor.

Usage

.rel_floor(brts, link = 0L, rel_floor = 0.01)

Arguments

brts

Branching times (crown age first, or any order).

link

Integer link code: 0 linear, 1 exponential, 2 gaussian.

rel_floor

Dimensionless floor. Default 1e-2.

Value

A positive scalar.
