Description

The parent recorded for a lineage born at t is the last observed branching at or before t. A lineage born before the first observed branching has none, and max(0L, ...) makes it observed node 0, which is not yet born then; .aug_to_Ltable refuses that attachment rather than building a tas with a negative edge. See the .augment_tree_bdi documentation for what that costs and what fixing it would take.

Usage

.bdi_to_tree_df(
  species,
  bt,
  tp,
  unsampled = numeric(0),
  obs_parent_id = NULL,
  obs_focal_ts = NULL,
  aug_id = NULL,
  aug_par = NULL,
  uns_id = NULL,
  uns_par = NULL
)
