Description

Two estimators are available:

Usage

.is_fhat(logf, log_q, bias_correct = FALSE, K = 2L, n_zero_weight = 0L)

Arguments

logf

Numeric vector of log p(obs, z | theta) for valid trees.

log_q

Numeric vector of log q(z | obs, theta) for valid trees.

bias_correct

Logical; use moment-based bias correction (default FALSE).

K

Integer truncation order for the moment series (default 2).

n_zero_weight

Integer; number of completed augmentations that had zero IS weight. These contribute w = 0 to the IS sum and inflate the denominator accordingly (default 0).

Details

Default (bias_correct = FALSE): the standard log-sum-exp estimator \(\log\bar{L} = \log\!\left(\frac{1}{n}\sum_i L_i\right)\), computed in numerically stable form. \(\bar{L}\) is an unbiased estimator of \(p(\mathrm{obs}\mid\theta)\), but \(\log\bar{L}\) slightly underestimates \(\log p\) (Jensen's inequality).

Bias-corrected (bias_correct = TRUE): uses the exact identity

\[\log\bar{L} = \hat\ell + \log\!\left(1 + \sum_{k=2}^{\infty} \frac{m_k}{k!}\right), \qquad m_k = \frac{1}{n}\sum_i(\log L_i - \hat\ell)^k\]

truncated at order K (default 2). The K=2 approximation is \(\hat\ell + \log(1 + m_2/2)\), equivalent to the log-normal correction \(\mu + \sigma^2/2\). With the full series (\(K\to\infty\)) the two estimators are identical; the truncation is the approximation.

Trees that hit computational limits (max_missing, max_lambda) are discarded entirely – they are simulator failures, not IS samples. Trees that completed augmentation but have zero IS weight (w = 0 because lambda = 0 under the current parameters) are legitimate IS samples and are included in the denominator via n_zero_weight.
