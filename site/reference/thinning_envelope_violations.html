Description

The thinning sampler accepts a candidate speciation time with probability nh(t) / lambda_max. A value above 1 means the envelope lambda_max did not dominate the rate on that segment. The counter accumulates over every augmentation call in the session.

Usage

thinning_envelope_violations(reset = FALSE)

Arguments

reset

Logical; zero the counter after reading it.

Value

Number of candidates with acceptance probability above 1 since the last reset.
