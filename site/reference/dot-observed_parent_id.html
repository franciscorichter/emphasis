Description

The ED covariate needs to know which lineage is which across events, which the tip start of .observed_parent_tip_start does not say. Lineages are named as the C++ layer names them: the two crown lineages are -2 (the one that splits first) and -3; the daughter born at the k-th observed branching event (forward-time order, 0-based) is lineage k. Which child of a node continues the parent's lineage is fixed by a convention that any consistent rule would do for: the child whose subtree holds the lowest tip label continues, the other is the daughter.

Usage

.observed_parent_id(phy)

Arguments

phy

A phylo object.

Value

Integer vector of length Nnode(phy) - 1, in forward-time order: the id of the lineage splitting at each event.
