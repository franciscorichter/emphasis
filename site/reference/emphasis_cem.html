Description

Implements the Cross-Entropy Method (CEM) with an IS log-likelihood objective. A population of parameter particles is evaluated via IS (fhat), the elite fraction is retained, and the remainder is refilled by perturbing elite copies.

Usage

emphasis_cem(
  brts,
  max_iter,
  num_points,
  max_missing,
  sd_vec,
  lower_bound,
  upper_bound,
  maxN = 10L,
  sample_size = 1L,
  shared_trees = FALSE,
  bias_correct = FALSE,
  disc_prop = 0.5,
  tol = 1e-04,
  patience = 5L,
  sd_decay = 0.85,
  sd_min_frac = 0.01,
  verbose = FALSE,
  num_threads = 1L,
  model = c(0L, 0L, 0L),
  link = 0L,
  cond_fun = NULL,
  max_time = NULL,
  rho = 1
)

Arguments

brts

Numeric vector of branching times.

max_iter

Maximum number of iterations (hard cap).

num_points

Population size.

max_missing

Max extinct lineages per augmentation.

sd_vec

Initial perturbation SD per parameter (8-element).

lower_bound, upper_bound

Search bounds (8-element).

maxN

Max augmentation attempts per particle. Default 10.

sample_size

Trees simulated per particle per evaluation. Default 1.

shared_trees

If TRUE, use pooled-tree estimator (Mode 2). Default FALSE (independent, Mode 1).

bias_correct

If TRUE, apply moment-based bias correction to the IS log-likelihood. Default FALSE.

disc_prop

Elite fraction retained per iteration. Default 0.5.

tol

Minimum improvement in best fhat required to avoid incrementing the plateau counter. Default 1e-4.

patience

Consecutive plateau iterations before early stopping. Default 5.

sd_decay

Multiplicative factor applied to sd_vec when the best log-likelihood has not improved. Default 0.85. Set to NULL to use the legacy linear annealing schedule.

sd_min_frac

Minimum SD as a fraction of the initial sd_vec. Default 0.01 (1%). SD will not decay below this floor.

verbose

Print iteration summaries. Default FALSE.

num_threads

Parallel threads. Default 1.

model

Length-3 binary integer vector c(use_N, use_M, use_D).

link

Integer link code: 0 = linear, 1 = exponential.

rho

Sampling fraction (0, 1]. Default 1 (complete sampling).

Details

Adaptive SD annealing: The perturbation SD is decayed multiplicatively (factor sd_decay, default 0.85) only when the best log-likelihood has not improved by more than tol in the current iteration. When the likelihood is still improving, the SD is held constant to maintain exploration. A minimum SD floor (sd_min_frac * initial_sd, default 1% of initial) prevents complete collapse. This replaces the former linear annealing schedule which coupled the SD decay to max_iter and could cause premature collapse on easy problems or insufficient exploration on hard ones.

Stopping rules (first triggered wins):

  1. Plateau: best fhat has not improved by more than tol for patience consecutive iterations and the SD has reached its floor – the population has both converged in likelihood and exhausted its perturbation budget.

  2. Hard cap: max_iter iterations reached (safety limit).

Value

A list:

best_loglik

fhat of best particle per completed iteration (length = actual iterations run, \(\leq\) max_iter).

best_pars

Parameter matrix, one row per iteration.

obtained_estim

Globally best parameter vector.

loglik_var

Bootstrap variance of fhat at best particle (NA if sample_size = 1).

converged

Character string naming the stopping rule that fired: "annealing", "plateau", or "max_iter".

time

Elapsed proc.time().
