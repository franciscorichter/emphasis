Description

Unified entry point for parameter inference under the general diversification model. Accepts a simulated or empirical tree, extracts branching times (pruning to extant tips if needed), and dispatches to the chosen optimisation back-end.

Usage

estimate_rates(
  tree,
  method = c("mcem", "cem", "gam"),
  model = "cr",
  init_pars = NULL,
  control = list(),
  link = "exponential",
  cond = NULL
)

Arguments

tree

One of:

  • a phylo object (extant tips only recommended),

  • the list returned by simulate_tree ($tes is used automatically, falling back to a pruned $tas), or

  • a numeric vector of branching times (crown-age ordering).

The covariate D is a lineage's pendant age – measured from the last time that lineage became a tip – centred on the mean over the alive lineages, so it is a function of the topology and not of the branching times alone. A phylo (or a simulate_tree result) carries it; a bare numeric vector does not, and every observed lineage is then recorded as dating from the crown, which leaves D = 0 at every observed branching event. Fit "d" or "nd" from a tree, not from branching times.

method

Optimisation method:

"mcem"

Monte Carlo Expectation-Maximisation (default). Iterates E- and M-steps until parameters stabilise (max relative change < tol for patience consecutive iterations) or max_iter is reached. Requires init_pars.

"cem"

Monte Carlo Cross-Entropy Method. Initialises a particle population randomly within the bounds and evolves it until convergence (annealing exhausted, plateau, or control$max_iter reached). Does not need init_pars.

"gam"

GAM-based MLE. Evaluates the IS log-likelihood on a grid spanning the bounds, fits a smooth GAM surface, and optimises it via L-BFGS-B. One-shot (non-iterative); no init_pars needed. Requires the mgcv package.

model

Model specification. Accepts:

  • a formula such as ~ N, ~ N + D, ~ N + ED or ~ N + K,

  • a string shortcut ("cr", "dd", "d", "nd", "ed", "ned", "edc", "nedc", "k", "nk"), or

  • an integer vector c(use_N, use_M, use_D, use_ED, use_K) (use_M is internal only and should be 0; a shorter vector is an earlier layout and is padded; use_ED = 3 selects the centred covariate).

model = "all" fits the nested ladder cr, dd, nd, ned, nk (the last two need a phylo and are left out on the gaussian link), each started from the estimate of the model it nests, with each model's box from auto_bounds unless control$bounds names one per model, and returns the fits with their compare_models table and its chosen model, the fewest parameters within 2 AIC of the minimum (an emphasis_fits object); control$models restricts the ladder. Default "cr" (constant rate). "nd" (~ N + D) is diversity and age-imbalance; "ned" (~ N + ED) diversity and evolutionary distinctiveness, which needs a phylo. "nedc" (~ N + EDc) reads ED minus its mean over the lineages alive at the same time, a covariate with clade mean zero, so that beta_ED carries only the within-clade contrast and none of the clade-level level that N tracks. "nk" (~ N + K) is diversity and the number of speciation events on the path from the crown to the lineage, hidden splits counted; it needs a phylo and runs on the thinning sampler.

init_pars

Starting parameter vector. Required for "mcem"; ignored for "cem". If NULL with "mcem", the midpoint of the bounds is used, with covariate slopes started at 0 (linear link) so that lambda stays positive during the early E-steps.

control

Named list of tuning parameters. Must include lower_bound and upper_bound. Use estimate_rates_control to inspect other defaults. Key entries:

lower_bound

Numeric vector of lower parameter bounds. Length must be 2 + 2*sum(model). Order: c(beta_0, [beta_N], [beta_D], gamma_0, [gamma_N], [gamma_D]) (D = age-imbalance covariate; M is internal only).

upper_bound

Numeric vector of upper parameter bounds (same order).

verbose

Print progress messages. Default FALSE.

link

Link function: "exponential" (default), rate = exp(eta), under which the intercepts beta_0 and gamma_0 are log rates; "linear", rate = max(0, eta), under which the parameters are rates and a covariate can drive a rate to zero, where it is clipped; "gaussian", beta_0 * exp(-(eta_cov - 1)^2 / 2), is experimental: it has been used only in a convergence study of the surrogate proposal's fixed-point iteration, never in an estimation experiment; it is not available for ED or K models, and every model with a covariate is fitted on it with the thinning proposal.

cond

The survival probability to condition on, or NULL (default) for no conditioning. When provided, the log-likelihood is conditioned: \(\ell_{\rm cond} = \ell - \log P_\theta(S)\), where \(P_\theta(S)\) is the probability that both crown lineages leave a sampled descendant at the present. Three forms are accepted: a function of the parameter data frame that returns \(P_\theta(S)\) (the probability, not its log), a GAM from train_GAM, or a nnet object (see predict_survival). The GAM is not accurate enough to condition on; the section ‘Conditioning on survival’ says what to pass instead.

Conditioning on survival

The survival emulator of train_GAM is not adequate for any lineage-level model. In experiment E43 (https://franciscorichter.github.io/emphasis/experiments/E43.html), GAMs trained on 2000, 5000 and 20 000 simulated clades for each of d, nd, ed, edc, ned, nedc, k and nk had a 90th-percentile error of \(\log P(S)\) of 0.44 to 2.56, against the 0.05 its adequacy rule required, and the error did not fall with the training size.

Under cr and dd, condition on the exact survival probability. The package does not export a function for it: pass one to cond. The function receives a data frame with one row per parameter point and columns named as the parameters (beta_0, gamma_0 under cr), and returns \(P_\theta(S)\), one value per row. Under constant rates on the exponential link, with \(\lambda = e^{\beta_0}\), \(\mu = e^{\gamma_0}\), \(d = \lambda - \mu\), crown age \(T\) and sampling fraction \(\rho\), one crown lineage leaves a sampled descendant at the present with probability

\[p = \frac{\rho d}{\rho\lambda + (\lambda(1-\rho) - \mu)e^{-dT}}\]

(\(p = \rho / (1 + \rho\lambda T)\) when \(\lambda = \mu\)); the two crown lineages are independent, so \(P_\theta(S) = p^2\). The last example below codes it. Under dd the exact value solves the master equation of the clade size, which the package does not provide. E43's Monte Carlo reference agreed with the exact values to a median error of 0.007 (cr) and 0.008 (dd) in \(\log P\).

Under a lineage-level model, either fit without conditioning or pass a function that returns a direct Monte Carlo estimate of \(P_\theta(S)\) at each row: the share of single forward draws from simulate_tree (max_tries = 1) in which both crown lineages leave a sampled descendant, a clade that reaches the lineage cap counted as surviving (at \(\rho = 1\), the share with status "done" or "too_large"). At a standard error of 0.01 in \(\log P\), one such estimate took E43 a median of 2 to 29 seconds of one core, depending on the model, and the M-step evaluates cond at every parameter value it tries.

Value

A list with class "emphasis_fit" containing:

pars

Named numeric vector of parameter estimates.

loglik

Final log-likelihood estimate. For MCEM this is the importance-sampling estimate at the returned parameters, and is NA when the E-step evaluating them failed.

loglik_var

Bootstrap variance of loglik due to Monte Carlo noise. Populated automatically when control$num_trees >= 2 (B = 200 replicates); NA when num_trees = 1.

n_pars

Number of free parameters (used for AIC): parameters with lower_bound == upper_bound are fixed and not counted.

AIC

Akaike Information Criterion: -2 * loglik + 2 * n_pars.

method

Method used ("mcem" or "cem").

model

Resolved binary model vector.

rho

The sampling fraction the fit was computed at, after the control merge.

stop_reason

Why the MCEM run stopped ("converged", "max_iter", "time_budget", "e_step_failure", "m_step_failure"); NA for other methods.

iterations

Number of completed MCEM iterations (0 when every E-step failed); NA for other methods.

n_failed

Number of E- or M-step failures over the MCEM run; NA for other methods.

notes

Named character vector of what the measurements and the run say about this fit: size, starved and turnover (emitted as a warning or messages when the fit is made), mean_field (the surrogate proposal's mean-field iteration was relaxed below the full step, ran under a damping other than "auto", or did not converge within its sweep budget: the setting, the sweeps taken, the relaxation and residual of the last E-step, and how many E-steps of the run relaxed or failed to converge) and clock (max_time ran out inside an E-step or an M-step). print() shows the last two.

details

Full output from the back-end function (.mcem_dynamic_fresh or emphasis_cem).

Examples

set.seed(1)
tr  <- simulate_tree(pars = log(c(0.5, 0.1)), max_t = 4, model = "cr")
phy <- tr$tes
# Exponential link (the default): the intercepts are log rates
fit <- estimate_rates(phy, method = "mcem", model = "cr",
  control = list(lower_bound = c(-3, -5), upper_bound = c(1, 0),
                 max_iter = 10, num_trees = 50))
fit

# Diversity-dependent model on the same tree
fit_dd <- estimate_rates(phy, method = "mcem", model = "dd",
  control = list(lower_bound = c(-3, -0.1, -5, -0.1),
                 upper_bound = c(1, 0.1, 0, 0.1),
                 max_iter = 10, num_trees = 50))
fit_dd$pars

# Conditioning a cr fit on its exact survival probability, P(S) = p^2
cond_cr <- function(T, rho = 1) function(pars) {
  lambda <- exp(pars$beta_0)
  mu     <- exp(pars$gamma_0)
  d      <- lambda - mu
  p <- ifelse(abs(d) < 1e-12, rho / (1 + rho * lambda * T),
              rho * d / (rho * lambda + (lambda * (1 - rho) - mu) * exp(-d * T)))
  p^2
}
crown_age <- max(ape::branching.times(phy))
fit_cond <- estimate_rates(phy, method = "mcem", model = "cr",
  cond = cond_cr(T = crown_age),
  control = list(lower_bound = c(-3, -5), upper_bound = c(1, 0),
                 max_iter = 10, num_trees = 50))
fit_cond
