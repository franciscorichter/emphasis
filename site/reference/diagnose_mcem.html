Description

Computes convergence and importance-sampling quality diagnostics from the output of estimate_rates with method = "mcem".

Usage

diagnose_mcem(
  x,
  plot = TRUE,
  lower_bound = NULL,
  upper_bound = NULL,
  true_pars = NULL
)

Arguments

x

An emphasis_fit object (from estimate_rates with method = "mcem") or the raw list from .mcem_dynamic_fresh.

plot

Logical; if TRUE (default), produce diagnostic plots.

lower_bound, upper_bound

Optional numeric vectors for bound lines.

true_pars

Optional numeric vector of true parameter values (for simulation studies). Red dashed lines are drawn at these values.

Convergence ($convergence)

A data frame with one row per EM iteration. The trace's last row, the final E-step at the returned parameters, is not an iteration and is not included; the table therefore has fit$iterations rows and its fhat of the final E-step is reported as $final_fhat. Columns:

iteration

Iteration index.

fhat

IS log-likelihood at the previous iterate (the E-step value the M-step of this iteration maximised).

delta_max

Maximum relative parameter change from the previous iteration, each coordinate measured against its own magnitude.

rejected

Draws rejected in the iteration's E-step: n_rejected (the sum over rejection channels) where the trace carries it, else the trace's own rejected column.

num_trees

Number of augmented trees used.

time

Wall-clock time for the iteration (ms).

IS quality ($IS_quality)

Importance-sampling diagnostics from the final EM iteration:

ESS

Effective sample size.

ESS_fraction

ESS as a fraction of num_trees.

mean_lw, sd_lw

Mean and SD of IS log-weights.

fhat

IS log-likelihood at the final parameters.

loglik_var

Bootstrap variance of fhat.

Value

A list of class "mcem_diagnostics" (invisibly) with components convergence, stop_reason, final_fhat, IS_quality, and final_IS.

Examples

set.seed(1)
tr  <- simulate_tree(pars = c(0.5, 0.1), max_t = 4, model = "cr")
phy <- tr$tes
fit <- estimate_rates(phy, method = "mcem", model = "cr",
  control = list(lower_bound = c(0, 0), upper_bound = c(2, 1),
                 max_iter = 10, num_trees = 50))
diagnose_mcem(fit, lower_bound = c(0, 0), upper_bound = c(2, 1))
