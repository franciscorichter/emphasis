Description

Computes convergence and importance-sampling quality diagnostics from the output of estimate_rates with method = "mcem".

Diagnostic plots include:

Log-likelihood trace

fhat vs. EM iteration, showing convergence of the sequence.

Parameter traces

Per-parameter estimates across iterations, with optional bound and true-value lines.

Parameter stability

Max relative parameter change (delta_max) vs.\ iteration; convergence is declared when this falls below tol for patience consecutive iterations.

IS weight histogram

Distribution of IS log-weights at the final iteration, annotated with ESS.

Usage

diagnose_mcem(x, plot = TRUE, lower_bound = NULL,
              upper_bound = NULL, true_pars = NULL)

Arguments

x

An emphasis_fit object (from estimate_rates with method = "mcem") or the raw list from the internal .mcem_dynamic_fresh function.

plot

Logical; if TRUE (default), produce diagnostic plots.

lower_bound

Optional numeric vector of lower parameter bounds. Dashed orange lines are drawn at these values in parameter trace panels.

upper_bound

Optional numeric vector of upper parameter bounds. Dashed purple lines are drawn at these values in parameter trace panels.

true_pars

Optional numeric vector of true parameter values (for simulation studies). Red dashed lines are drawn at these values.

Value

A list of class "mcem_diagnostics" (invisibly) with:

convergence

Data frame with per-iteration fhat, delta_max (max relative parameter change), rejected, num_trees, and time.

stop_reason

Why MCEM stopped: "converged", "max_iter", or "e_step_failure".

IS_quality

List with ESS, mean/sd of log-weights, and bootstrap variance at the final iteration.

final_IS

Raw IS components (logf, logg, lw) from the final E-step.

Examples

## Not run: 
sim <- simulate_tree(c(0.5, 0.1), max_t = 5, model = "cr")
fit <- estimate_rates(sim, method = "mcem", model = "cr",
  control = list(lower_bound = c(0, 0), upper_bound = c(2, 1)))
diagnose_mcem(fit, lower_bound = c(0, 0), upper_bound = c(2, 1))

## End(Not run)
