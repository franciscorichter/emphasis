Description

Tools for simulating phylogenetic trees, augmenting missing lineages, and fitting diversification models using Monte Carlo EM, Cross-Entropy Method, and importance sampling.

Details

The package revolves around four workflows:

  • Simulation: 'simulate_tree()' for forward and conditional simulation.

  • Augmentation: augment_trees() draws IS-weighted augmented trees; eval_logf() scores pre-computed trees at any parameter point.

  • Estimation: 'estimate_rates()', 'emphasis_cem()' (CEM back-end).

  • Diagnostics: 'train_GAM()' plus plotting utilities.

Heavy computations are delegated to C++ via 'Rcpp' / 'RcppParallel' for performance.
