Description

Augments an observed extant tree (given by its branching times) with stochastically drawn extinct lineages, and returns the simulated trees together with their log proposal probabilities. Scoring (logf) and IS aggregation (fhat) are intentionally left to the R layer via eval_logf and .is_fhat.

Usage

augment_trees(
  brts,
  pars,
  sample_size,
  maxN,
  max_missing,
  max_lambda,
  num_threads,
  model = as.integer(c(0, 0, 0)),
  link = 0L,
  rho = 1,
  parent_tip_start = as.numeric(c()),
  seed = 0L,
  parent_id = as.integer(c())
)

Arguments

brts

Numeric vector of branching times (crown age first, sorted decreasing).

pars

Numeric vector of 8 model parameters c(beta_0, beta_N, beta_M, beta_D, gamma_0, gamma_N, gamma_M, gamma_D).

sample_size

Number of valid augmented trees to collect.

maxN

Maximum total augmentation attempts (including failures).

max_missing

Maximum extinct lineages per augmented tree.

max_lambda

Upper bound on the speciation rate (thinning bound).

num_threads

Threads for parallel augmentation.

model

Integer vector c(use_N, use_P, use_E).

link

Link function: 0 = linear, 1 = exponential.

rho

Sampling fraction in (0, 1].

parent_tip_start

Tip start of the lineage that splits at each observed branching event, in the same forward-time order as brts (that is, rev of the decreasing brts); one entry per event, or one per node with the last ignored. Empty (the default) means the topology is not available: every observed lineage is then recorded as dating from the crown and every observed event gets D = 0, which is what a bare branching-time vector has always produced.

seed

Positive integer seeding the C++ sampler. 0 (the default) draws one from R's generator, so set.seed() reaches the sampler whether or not a seed is passed. Two calls carrying the same seed, the same arguments and num_threads = 1 draw the same trees.

Value

A named list:

trees

List of augmented-tree data frames.

logf

Per-tree log p(obs, z | theta).

logg

Per-tree log q(z | obs, theta).

rejected

Unhandled rejections.

rejected_overruns

Rejected: too many extinct lineages.

rejected_lambda

Rejected: lambda bound exceeded.

rejected_zero_weights

Rejected: zero IS weight (log weight -Inf).

rejected_nonfinite

Rejected: log weight +Inf or NaN.

num_trees

Number of trees returned (length(trees)).

envelope_violations

Thinning candidates drawn during this call whose acceptance probability exceeded 1, i.e. the envelope did not dominate the rate. Non-zero means the draws are not from the density logg charges them; a warning is issued.

time

Elapsed time (ms).
