Description

Runs a multi-stage estimation workflow with automatic bounds detection, exploratory fits (GAM and CEM), and optional MCEM refinement. Each stage is timed and logged. If MCEM fails, the best exploratory result is returned.

Usage

emphasis_pipeline(
  tree,
  model = "cr",
  link = "linear",
  stages = c("bounds", "gam", "cem", "mcem"),
  control = list(),
  verbose = TRUE
)

Arguments

tree

A phylo object, branching-time vector, or simulate_tree result.

model

Model specification: "cr", "dd", "d", "nd", "ed", "ned", "k", "nk", a formula (e.g. ~ N + D, ~ N + ED, ~ N + K), or a binary vector.

link

"linear" (default), "exponential", or "gaussian".

stages

Character vector of stages to run. Default c("bounds", "gam", "cem", "mcem"). Remove stages to skip them, e.g. c("bounds", "gam") for a quick exploratory fit.

control

Named list with optional sub-lists bounds, gam, cem, mcem to override defaults for each stage. Common parameters (num_threads, default 1, max_missing, max_time, rho) can be set at the top level and are inherited by all stages. rho, the sampling fraction in (0, 1], is inherited by the bounds, gam, cem and mcem stages alike, and a value nested under control$gam, control$cem or control$mcem overrides the inherited one for that stage.

verbose

Logical. If TRUE (default), print progress and a summary log to the console.

Stages

  1. Bounds: auto_bounds detects parameter bounds and trains a survival GAM for conditioning.

  2. GAM: Fits a smooth likelihood surface over a grid and optimises it. Fast, one-shot.

  3. CEM: Cross-entropy global search. Stochastic, no init needed. Explores the space differently than GAM.

  4. MCEM: Monte Carlo EM starting from the best init found in stages 2–3. Local refinement for precise estimates.

Value

A list of class "emphasis_pipeline" with:

pars

Named parameter vector from the best stage.

loglik

Log-likelihood from the best stage.

AIC

AIC from the best stage.

best_stage

Which stage produced the final result.

rho

The sampling fraction the best stage ran at.

log

Data frame with one row per stage: stage name, pars, loglik, AIC, elapsed seconds, status, rho.

mcem_trace

If MCEM ran, a data frame of per-iteration fhat and parameter values. NULL otherwise.

bounds

The auto_bounds result (bounds + survival GAM).

fits

Named list of individual emphasis_fit objects.

Examples

set.seed(1)
tr  <- simulate_tree(pars = c(0.5, 0.1), max_t = 4, model = "cr")
phy <- tr$tes
# CEM stage only, with the search box given
res <- emphasis_pipeline(phy, model = "cr", stages = "cem",
  control = list(lower_bound = c(0, 0), upper_bound = c(2, 1),
                 cem = list(max_iter = 3, num_particles = 10)),
  verbose = FALSE)
res

# Bounds found automatically, then CEM
res2 <- emphasis_pipeline(phy, model = "cr", stages = c("bounds", "cem"),
  control = list(cem = list(max_iter = 3, num_particles = 10)),
  verbose = FALSE)
res2$log
