Description

Fits the two 4-parameter single-covariate models – diversity dependence (DD, covariate N) and age-imbalance dependence (D, covariate D = E - M) – to the same tree using a two-stage MCDE -> MCEM workflow, then ranks them by AIC and computes AIC weights.

Usage

select_diversification_model(
  tree,
  lower_bound = c(0.1, -0.5, 0, -0.5),
  upper_bound = c(3, 0.5, 1, 0.5),
  link = "linear",
  control = list(),
  verbose = FALSE
)

Arguments

tree

Ultrametric tree. Accepts a phylo object, a simulate_tree result, or a numeric branching-time vector.

lower_bound

Length-4 numeric vector of lower parameter bounds: c(beta_0, beta_X, gamma_0, gamma_X). Default c(0.1, -0.5, 0, -0.5).

upper_bound

Length-4 numeric vector of upper parameter bounds. Default c(3, 0.5, 1, 0.5).

link

Link function: "linear" (default), "exponential", or "gaussian".

control

Named list with optional sub-lists cem and mcem to override tuning defaults for each stage. Bounds and verbose are taken from the outer arguments; no need to repeat them here. Example: list(cem = list(max_iter = 20, num_particles = 50), mcem = list(num_trees = 300, tol = 0.05)).

verbose

Print progress messages. Default FALSE.

Details

Both models share the same parameter layout: c(beta_0, beta_X, gamma_0, gamma_X), so a single pair of bounds applies to both.

Value

A list of class "model_selection" with:

summary

Data frame with columns model, n_pars, loglik, AIC, delta_AIC, AICw, sorted by AIC.

best_model

Name of the best-supported model ("dd" or "d").

best_pars

Named parameter estimates of the best model.

fits

Named list of the emphasis_fit objects ($dd, $d).

Examples

## Not run: 
set.seed(42)
sim <- simulate_tree(pars = c(0.8, -0.02, 0.2, 0), model = "dd", max_t = 8)
sel <- select_diversification_model(sim,
  lower_bound = c(0.1, -0.5, 0, -0.5),
  upper_bound = c(3,    0.5, 1,  0.5))
sel
sel$best_model   # "dd"
sel$best_pars

## End(Not run)
