Description

Fits a binomial GAM to estimate P(survival | parameters) from forward simulations run with max_tries = 0. Each simulation row has a binary outcome: 1 if both crown lineages reached the present (status "done") or the clade passed the lineage cap ("too_large"), 0 if it went extinct. A clade stopped at the cap has survived so far, and the conditional likelihood divides by the probability of survival; counting it as extinct teaches the GAM a survival near zero wherever clades grow fast, which then rewards the fit for moving there (E36c of the paper).

Usage

train_GAM(
  simulations,
  pars_mat,
  model = "cr",
  spline_type = c("univariate", "bivariate"),
  verbose = TRUE
)

Arguments

simulations

List of simulate_tree() outputs (one per row of pars_mat), produced with max_tries = 0.

pars_mat

Numeric matrix whose rows are the parameter vectors used to generate simulations. Column names are used as predictor names; if absent, names are auto-generated from model.

model

String or binary integer vector (length 3 or 4) matching the model used in simulation. Used only when pars_mat has no column names. Default "cr".

spline_type

"univariate" (default) fits independent smooth terms s(x) for each varying predictor. "bivariate" fits tensor-product smooths te(x, y) for every pair of varying predictors, which can capture interaction effects.

verbose

Report the number of simulations and the survival rate (default TRUE).

Value

A gam object (binomial family) representing \(P(\text{survival} \mid \theta)\).

Examples

set.seed(1)
pars_mat <- cbind(beta_0  = runif(100, 0.3, 1.2),
                  gamma_0 = runif(100, 0.05, 0.5))
sims <- simulate_tree(pars = pars_mat, max_t = 4, model = "cr",
                      max_tries = 0)
gam_uni <- train_GAM(sims$simulations, pars_mat, model = "cr")
predict_survival(gam_uni, data.frame(beta_0 = 0.8, gamma_0 = 0.2))
