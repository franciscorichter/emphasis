Description

Returns NULL when the sampler is available. The reasons are ordered so that the first thing wrong with the call is the one reported.

Usage

.bdi_unsupported_reason(model_bin, link, rho = 1)

Arguments

model_bin

Length-3 binary model vector c(use_N, use_M, use_D).

link

Integer link code: 0 linear, 1 exponential.

rho

Sampling fraction in (0, 1]. Default 1.
