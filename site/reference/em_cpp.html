Description

function to perform one step of the E-M algorithm

Usage

em_cpp(
  brts,
  init_pars,
  sample_size,
  maxN,
  max_missing,
  max_lambda,
  lower_bound,
  upper_bound,
  xtol_rel,
  num_threads,
  copy_trees,
  model = as.integer(c(0, 0, 0)),
  link = 0L,
  rho = 1,
  rconditional = NULL,
  parent_tip_start = as.numeric(c()),
  seed = 0L,
  parent_id = as.integer(c())
)

Arguments

brts

vector of branching times

init_pars

vector of initial parameter files

sample_size

number of samples

maxN

maximum number of failed trees

max_missing

maximum number of species missing

max_lambda

maximum speciation rate

lower_bound

vector of lower bound values for optimization, should be equal in length to the vector of init_pars

upper_bound

vector of upper bound values for optimization, should be equal in length to the vector of init_pars

xtol_rel

relative tolerance for optimization

num_threads

number of threads used.

copy_trees

if set to true, the trees generated are returned as well

model

integer vector of length 3: c(use_N, use_P, use_E)

link

link function: 0 = linear (max(0,...)), 1 = exponential

rho

sampling fraction in (0, 1]

rconditional

R function that evaluates the GAM function.

parent_tip_start

tip start of the lineage that splits at each observed branching event, in the same forward-time order as brts; empty (the default) when only branching times are available, in which case every observed lineage is recorded as dating from the crown and D = 0 at every observed event.

seed

positive integer seeding the C++ sampler; 0 (the default) draws one from R's generator, so set.seed() reaches the sampler whether or not a seed is passed.

Value

a list with the following components:

trees

list of trees

rejected

number of rejected trees

rejected_overruns

number of trees rejected due to too large size

rejected_lambda

number of trees rejected due to lambda errors

rejected_zero_weights

number of trees rejected due to zero weight (log weight -Inf)

rejected_nonfinite

number of trees rejected due to a +Inf or NaN log weight

num_trees

number of trees the E-step returned

estimates

vector of estimates

nlopt

nlopt status

fhat

vector of fhat values

time

time elapsed

weights

vector of weights

logf

vector of log p(obs, z_i | theta) for each valid tree

logg

vector of log q(z_i | obs, theta) for each valid tree
