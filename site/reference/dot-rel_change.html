Description

The step in each coordinate is measured against that coordinate's own magnitude, with a floor so that a coordinate at or near zero is not measured against itself. The floor carries the units of the parameter (see .rel_floor), so the statistic is unchanged when the tree and the rates are expressed in another unit of time.

Usage

.rel_change(new, old, floor_val)

Arguments

new, old

Parameter vectors of equal length.

floor_val

Floor of the denominator, from .rel_floor.

Value

The largest relative coordinate change.
