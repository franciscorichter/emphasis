Description

Model::pendant_pd_at reads P off the node that governs the segment a candidate time falls in; Model::nh_rate is the intensity of the sampler's birth process there. This exposes both, so a test can hold P against an independent recomputation from the augmented tree and against pd + n * (t - brts) of the governing node, and can scan the intensity over a segment to check that its value at the segment start dominates it.

Usage

eval_nh_rate(
  pars,
  tree,
  times,
  model = as.integer(c(0, 0, 0)),
  link = 0L,
  rho = 1
)

Arguments

pars

Numeric vector of 8 model parameters.

tree

One augmented-tree data frame.

times

Numeric vector of times at which to evaluate.

model

Integer vector c(use_N, use_M, use_D).

link

Link function: 0 = linear, 1 = exponential.

rho

Sampling fraction.

Value

A named list with pd (the pendant PD used) and nh (the non-homogeneous thinning rate) at each time.
