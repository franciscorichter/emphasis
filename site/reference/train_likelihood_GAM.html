Description

Takes the output of estimate_likelihood_surface and fits a smooth GAM approximation to the log-likelihood as a function of the model parameters.

Usage

train_likelihood_GAM(
  surface,
  par_names = NULL,
  spline_type = c("univariate", "bivariate")
)

Arguments

surface

Data frame returned by estimate_likelihood_surface. Rows with fhat = NA are dropped automatically.

par_names

Character vector of column names in surface to use as predictors. If NULL (default), all columns except fhat and n_trees are used.

spline_type

"univariate" (default) or "bivariate". See train_GAM for details.

Value

A gam object (Gaussian family) representing \(\hat\ell(\theta) \approx \log L(\theta \mid \text{data})\).
