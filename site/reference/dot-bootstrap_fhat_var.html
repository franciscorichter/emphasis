Description

Draws B bootstrap replicates (sampling with replacement from the IS log-weights lw = logf - log_q) and computes \(\hat\ell_{\rm BC,K}\) for each replicate. Returns the sample variance of the B estimates, which approximates \(\mathrm{Var}(\hat\ell_{\rm BC,K}(L))\) due to Monte Carlo noise.

Usage

.bootstrap_fhat_var(logf, log_q, K = 2L, B = 200L)

Arguments

logf

Numeric vector of log p(obs, z | theta) for valid trees.

log_q

Numeric vector of log q(z | obs, theta) for valid trees.

K

Moment truncation order (default 2).

B

Number of bootstrap replicates (default 200).

Details

This variance is used downstream for AIC uncertainty quantification: \(\mathrm{Var}(\Delta\mathrm{AIC}) = 4[\mathrm{Var}(\hat\ell_1) + \mathrm{Var}(\hat\ell_2)]\), enabling a Gaussian test of equal AIC.

Value

Numeric scalar: estimated variance of the log-likelihood estimator. NA if fewer than 2 valid log-weights are available.
