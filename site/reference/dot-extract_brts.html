Description

Returns the branching times in the crown-first (decreasing) order the C++ layer expects, carrying the per-node "parent_tip_start" attribute when the input was a tree rather than a bare numeric vector. Read it with .pts() and hand it to augment_trees() / em_cpp().

Usage

.extract_brts(tree)

Details

The attribute has one entry per node: the tip start of the lineage that splits at that observed branching event, then -1 for the terminal marker at the present, which is not an event. It is numeric(0) for a numeric input, where no topology exists.
