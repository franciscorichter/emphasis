Description

Evaluates the survival probability estimate_rates(cond = ) conditions through, in any of its three forms: a function that takes the parameter data frame and returns probabilities, a gam from train_GAM, or a nnet object.

Usage

predict_survival(gam_fit, newpars)

Arguments

gam_fit

A gam object returned by train_GAM, a nnet object trained on the same columns, or a function of a parameter data frame.

newpars

Numeric matrix or data frame of parameter values to predict at. Column names must match those used in train_GAM.

Details

The GAM is not accurate enough to condition on: in experiment E43 (https://franciscorichter.github.io/emphasis/experiments/E43.html) its 90th-percentile error of \(\log P(S)\) was 0.44 to 2.56 for every lineage-level model, against 0.05 required. Under cr and dd pass the exact survival probability as a function; the section ‘Conditioning on survival’ of estimate_rates gives the cr formula and the alternatives.

Value

Numeric vector of predicted survival probabilities.

Examples

set.seed(1)
# Exponential link (the default): the intercepts are log rates
pars_mat <- cbind(beta_0  = log(runif(100, 0.3, 1.2)),
                  gamma_0 = log(runif(100, 0.05, 0.5)))
sims <- simulate_tree(pars = pars_mat, max_t = 4, model = "cr",
                      max_tries = 1)
gam_fit <- train_GAM(sims$simulations, pars_mat, model = "cr")
predict_survival(gam_fit, data.frame(beta_0  = log(c(0.5, 1.0)),
                                     gamma_0 = log(c(0.1, 0.3))))
