Description

Mean-field state: Nhat(t) = k(t) + mhat(t), Phat(t) = P_obs(t) + Phat_miss(t), Ehat(t) = Phat(t) / Nhat(t). All three enter the rate function; inactive covariates (pars8 slopes pinned to 0) make the extension transparent for CR/DD and activate PD/EP/mixed models. The sweep budget is 60 because the iteration slows as rho falls: the unsampled extant lineages raise Nhat, which feeds back into the rates that produced them. On the 20-tip DD tree at K = 20 the fixed point is reached in 6 sweeps at rho = 1, 7 at 0.9, 14 at 0.5 and 27 at 0.2. The old budget of 20 therefore returned a non-converged mean field at small rho – delta = 2.9e-3 against tol = 1e-4 in that last case – and the loop still breaks on tol, so raising the cap cannot change a run that already converged.

Usage

.bdi_iterate(
  pars8,
  model_bin,
  link,
  bt,
  tp,
  max_iter = NULL,
  tol = 1e-04,
  n_grid = 500,
  use_gaussian_closure = TRUE,
  rho = 1,
  pd_mode = c("pendant", "faith"),
  damping = "auto"
)

Value

List with p_fun, Nhat_fun, Phat_fun, Ehat_fun, and the fixed-point diagnostics converged / delta / iterations, with omega (the relaxation of the last sweep), damping (the setting) and max_iter (the budget).
