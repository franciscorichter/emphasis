Description

For linear link, lambda = max(0, beta_0 + beta_X * X). If the slope is too negative, lambda becomes zero at observed covariate values, causing IS collapse. This clamps slopes so lambda stays positive at the maximum covariate value seen in the tree.

Usage

.validate_linear_init_pars(
  init_pars,
  model_bin,
  brts,
  lower_bound,
  upper_bound,
  verbose = FALSE
)
