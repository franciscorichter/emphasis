Description

The covariates \(M\) and \(D\) are functions of the pendant ages of the alive lineages, and a lineage's pendant age is measured from the last time it became a tip – its tip start, which is reset every time it speciates. For an observed branching event that is the forward time of the parent of the splitting node, and 0 for the two children of the crown.

Usage

.observed_parent_tip_start(phy)

Arguments

phy

A phylo object.

Details

Events are returned in forward-time order, the order the C++ layer builds the observed tree in, so the k-th entry belongs to the k-th observed node. A 2-tip tree has no non-crown internal node and returns numeric(0).

Value

Numeric vector of length Nnode(phy) - 1.
