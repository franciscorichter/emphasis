Description

For each row of pars_mat, augments sample_size trees via IS and computes the IS log-likelihood estimate (fhat). Returns a data frame ready for train_likelihood_GAM.

Usage

estimate_likelihood_surface(
  tree,
  pars_mat,
  model = "cr",
  sample_size = 200L,
  link = "linear",
  max_missing = 10000,
  max_lambda = 500,
  maxN = NULL,
  num_threads = 1L,
  bias_correct = FALSE,
  verbose = TRUE,
  max_time = NULL,
  rho = 1
)

Arguments

tree

A phylo object, branching-time vector, or anything accepted by estimate_rates.

pars_mat

Numeric matrix whose rows are compact parameter vectors (same layout as pars in estimate_rates).

model

Model specification: "cr", "dd", "d", "nd", "ed", "ned", "k", "nk", or a binary integer vector (length 3 to 5).

sample_size

Number of augmented trees per grid point (default 200).

link

"linear", "exponential", or "gaussian".

max_missing

Maximum missing lineages per augmentation (default 1e4).

max_lambda

Maximum speciation rate (default 500).

maxN

Total augmentation attempts per grid point. If NULL, set automatically.

num_threads

Number of threads for the C++ E-step.

bias_correct

Logical; if TRUE, use the moment-based bias-corrected IS estimator (truncated at order K). Default FALSE uses the standard log-mean-exp estimator.

verbose

Print progress (default TRUE).

rho

Sampling fraction (0, 1]. Default 1 (complete sampling).

Value

A data frame with columns for each parameter plus fhat (IS log-likelihood) and n_trees (number of valid trees obtained). Rows where IS failed have fhat = NA.
