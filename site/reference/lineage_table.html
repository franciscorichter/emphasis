Description

One row per lineage alive on each segment between consecutive events of an augmented tree: the segment's bounds, the covariates the rates read there (N, the clade mean pendant age M at the segment's end t1, the lineage's pendant start ts, so that D = (t1 - ts) - M, constant on the segment, and its ED at the segment start, growing at slope one within it), and whether the lineage's own event ends the segment (event: 0 none, 1 speciation, 2 extinction). These are the numbers the likelihood is built on; covariate_path runs a selection path over them.

Usage

lineage_table(tree)

Arguments

tree

An augmented-tree data frame with the topology (the frames augment_trees returns when given parent ids), or a phylo object, which is taken as fully observed.

Value

A data frame with columns seg, lineage, id, event, t0, t1, N, M, ts, ed0.
