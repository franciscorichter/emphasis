Description

Simulates fresh trees for every particle, pools them into a single set, and cross-evaluates: for each particle \(\theta_j\), computes

\[\hat{f}(\theta_j) = \log\text{mean}\exp\bigl( \text{logf}(z_i, \theta_j) - \log q(z_i, \theta_j)\bigr)\]

where both numerator and denominator are evaluated at the target particle \(\theta_j\). The trees \(z_i\) may have been simulated at any particle; what matters for IS correctness is that the proposal density \(q\) is evaluated at the same \(\theta_j\) used for \(p\).

Usage

.eval_shared(pop, input, num_threads)

Details

Tree caches are cleared between iterations (see .resample_particles with clear_cache = TRUE), so the pool contains only the current iteration's trees.

Value

Named list: updated pop, rej_lambda, rej_overruns, n_simulated.
