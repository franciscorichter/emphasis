### Critical

**H2 — BDI at rho < 1 targets the rho = 1 model.**
Statement: With control$rho < 1 the default BDI sampler (cr and dd, both links, `estimate_rates` and `simulate_tree(method = "bdi")`) never proposes unsampled-extant lineages and uses the rho = 1 conditioned process, so its fhat equals the complete-sampling likelihood plus n_tips·log(rho) and `estimate_rates(sampling = "bdi")` returns the rho = 1 MLE while printing "BDI (exact)"; the thinning path targets the correct model within IS error.
Evidence: `R/bdi.R:16-19` (no rho in `.bdi_p_cr`), `:451-456`, `:514` (survivors rejected), `:544,576` (only sentinels 1e11/0 written), `:687-691` (rho only to `eval_logf`), `:100-105` (`.bdi_supported` has no rho), dispatch `R/inference.R:359`, `R/simulate.R:345`; `inst/include/model.hpp:459-467`. 16-tip tree, rho = 0.5: BDI draws contain 0 unsampled nodes; logf shift exactly 16·log(0.5) = −11.0903549; BDI gap to the Stadler closed form −5.9 to −10.5 nats (θ-dependent), thinning gap −0.04 to −0.06 (rep sd 0.05–0.10); fits λ = 0.47 (rho = 1 MLE) vs 0.69 (rho = 0.5 MLE). 24-tip replicate, rho = 0.7: shift 24·log(0.7) exactly on both links and dd; fit λ = 0.7188 vs closed-form rho = 1 MLE 0.7128; 0 of 18 verbose messages mention rho.
Script: `dev/audit/checks/H2.R`, `H2_replicate.R`, `H2_simdispatch2.R`.
Fix: add `rho` to `.bdi_supported(model_bin, link, rho = 1)` returning FALSE for rho < 1; pass it at `inference.R:359`, `simulate.R:345`, label at `inference.R:788-790`; make the fallback message unconditional. Full fix: rho-aware BDI with p_ρ(t) and unsampled-extant events (t_ext = 5e10) in `.bdi_to_tree_df`.
cr/dd fit: No. At rho = 1 BDI fhat matches the Nee crown likelihood to 2e-13.
Interactions: H29 (pipeline never passes rho), H79 (rho unvalidated), H100 (rho untested), H95.

**H11 — dd/linear via BDI: zero rate → ±Inf logf → frozen M-step reported as converged.**
Statement: Under dd/linear via BDI (default sampler and link), augmented trees whose N reaches the zero of max(0, β0 + βN·N) get logf = −Inf, or +Inf when the zero-rate node is the last one added to `log_sum` and its running sum_ ≥ 0 (`model_helpers.hpp:129-136` flips a legitimate −Inf by the sign of sum_); `.augment_tree_bdi` applies no finiteness filter (unlike the thinning E-step), so a +Inf tree makes fhat and all w_norm NaN, and with only −Inf trees the objective Σ loglik·w is −Inf·0 = NaN at the init, so SBPLX returns the init (nlopt 4), delta_max = 0 counts toward patience, and the fit reports "converged" at whatever θ it held.
Evidence: `inst/include/model_helpers.hpp:129-147`, `src/M_step.cpp:47-49`, `R/bdi.R:686-703, 796-799, 840-865`, `R/inference.R:410-412`. Hand trees: A1 λ(2) = 0 → +Inf, A2 → −Inf, A3 → +Inf, A5 → −Inf. 9-tip tree, pars (1.5, −0.12, 0.4, 0): 75–100 of 200 trees −Inf, 0–1 +Inf, fhat NaN in 3/5 replicates. `estimate_rates` from the generating pars: fhat −17.44, NaN, NaN, delta 0 ×3, "converged" after 3 iterations. 30-tip replicate: package-clamped init (zero at 33.3) never moved (augmented N reached 40–41), three iterations delta 0, "converged", 54 −Inf trees in final_IS. Zero of λ drifts toward N_max (21.9 → 13.0) over 12 iterations.
Script: `dev/audit/checks/H11.R`, `H11_replicate.R`.
Fix: (1) `log_sum`: a zero or negative rate yields −Inf unconditionally; never derive the sign from sum_. (2) `.augment_tree_bdi`/`.mcem_bdi`: keep non-finite draws in the fhat denominator as zero weight, exclude them from the M-step tree set; treat all-non-finite as E-step failure. (3) `M_step.cpp` objective: skip w == 0 terms / guard non-finite loglik. (4) `bdi.R:840-865`: an iteration whose M-step returned init unchanged does not count toward patience; record non-finite counts.
cr/dd fit: Yes (dd). Any iteration where a BDI draw reaches N ≥ −β0/βN freezes the M-step; the fit reports "converged" at that θ; fhat NaN when a +Inf tree exists. cr unaffected (constant λ).
Interactions: H10, H12, H31, H8.

## 4. Refuted and inconclusive

- **H5** — refuted: `−log(2·tips + Ne)` is the exact parent-marginalisation multiplicity; exact-sampler fhat reproduces `bd_loglik`/`dd_loglik` up to −log((n−1)!) across θ and 2·log p1(T) on a 2-tip tree (`H5.R`, `H5_exactq.R`); the residual θ-dependent gap is H7.
- **H17** — refuted: ESS is invariant to zero-weight entries; `.ess_from_lw(c(0,−Inf,−Inf))` = 1 either way (`H17.R`).
- **H19** — refuted: no binomial coefficient under the labelled-augmentation convention; fhat(rho) matches the Stadler density with gap −0.02 to −0.06 vs a 2.3–9.4-nat shift if added (`H19.R`).
- **H25** — refuted: the softmax elite average is diffuse (entropy 87–99 % of log n), stable (SD ≤ 0.026), on the ridge, and the best-elite alternative carries a +0.48-nat winner's curse (`H25.R`, `H25_fresh.R`); the 0.6–0.9-nat CEM gap to the MLE is a search issue (H24/H42).
- **H26** — refuted: NA particles occur only where f = 0 (K ≤ N_obs − 2); maxN = 10 vs 200 give identical estimates (`H26.R`, `H26_probe2.R`); only a diagnostic label (NA vs −Inf) is worth changing.
- **H43** — refuted: inactive 8-slots stay exactly 0 in every CEM particle and M-step estimate (`H43.R`).
- **H49** — refuted: 0 of 30 000 rho = 1 trees carry the unsampled sentinel (`H49.R`).
- **H50** — refuted: `trunc_exp` does not stall (0.3 ms/tree at μ → 0) because the candidate rate cancels the expected rejections (`H50.R`); inverse-CDF is optional hardening (wave 3.6).
- **H52** — refuted: float32 event times give no zero edges or duplicate branching times below ~4 000 tips (`H52.R`, `H52_nan.R`); optional double conversion (wave 3.6).
- **H60** — refuted: the DD-branch breaks never caused a rejection in 1 200 draws; all rejections were genuine survivors (`H60.R`).
- **H80** — refuted: mgcv's binomial linkinv floors at 2.2e-16, so the unfloored `log(p_tree)` row-drop is unreachable (`H80.R`).
- Inconclusive: none. Every hypothesis reached a verdict; the only sub-claims left open are the CEM behaviour past the H1 cut (a cem run at s = 1e8 did not return in 10 min, `H1_cem_cut.R`) and the exact H1 gap magnitude for cem/gam, both subsumed by the H1 fix.
