# dev/

Working material, excluded from the package build by `.Rbuildignore`.

- `audit/` — the as-implemented map, the 105 hypotheses, the findings, and one reproduction
  script per finding.
- `validation/` — the MLE-recovery study: design, scripts, reference gate. A tier's trees,
  results, figures and tables are regenerated by `run.sh` and are not tracked.
- `pendant_*.R` — the scripts that compared the pendant-age covariates before and after the
  topology change. `pendant_baseline.R` captures a baseline from whichever build is loaded and
  `pendant_compare.R` diffs two captures; the `.rds` captures themselves are build-specific and
  are not tracked, so regenerate them against the two commits being compared.
