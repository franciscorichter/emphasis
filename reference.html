auto_bounds Automatically determine parameter bounds via forward simulation

Description

Starts from a safe centre point (low rates, zero covariates) and expands outward along each parameter axis using bisection to find the feasibility boundary — where trees transition from surviving with sensible size to going extinct or exploding. Much more efficient than blanket LHS sampling over a wide box. Optionally trains a survival GAM over the detected region; the bounds do not depend on it.

Usage

auto_bounds(
  tree,
  model = "cr",
  link = "exponential",
  n_test = 5L,
  bisect_steps = 8L,
  margin = 0.5,
  tip_range = c(0.1, 10),
  train_surv_gam = TRUE,
  num_threads = 1L,
  verbose = TRUE,
  rho = 1,
  surv_tries = 20L
)

Arguments

tree

A phylo object or anything accepted by estimate_rates.

model

Model specification: "cr", "dd", etc.

link

Link function: "exponential" (default), rate = exp(eta), under which the intercepts beta_0 and gamma_0 are log rates; "linear", rate = max(0, eta), under which the parameters are rates and a covariate can drive a rate to zero, where it is clipped.

n_test

Number of replicate simulations per candidate point to assess feasibility (default 5).

bisect_steps

Number of bisection steps per axis direction (default 8; gives ~1/256 resolution).

margin

Fractional expansion of detected bounds (default 0.5).

tip_range

Multiplier range for acceptable tip counts relative to the observed tree. Default c(0.1, 10).

train_surv_gam

If TRUE (default), train a survival GAM on the detected region, from 2000 single forward draws. The GAM is not accurate enough to condition a fit on (experiment E43; see train_GAM).

num_threads

Parallel threads for batch simulation (default 1).

verbose

Print progress (default TRUE).

rho

Sampling fraction (0, 1]. Default 1 (complete sampling).

surv_tries

Draws allowed per simulation, the first included, when judging whether a parameter vector produces surviving clades of a usable size: an extinct clade is redrawn up to this many times in all (passed to simulate_tree as max_tries). Default 20.

Value

A list with components:

lower_bound

Numeric vector of lower bounds (compact layout).

upper_bound

Numeric vector of upper bounds (compact layout).

survival_gam

A gam object if trained, else NULL.

center

The safe centre point used as starting location.

Examples

set.seed(1)
tr  <- simulate_tree(pars = log(c(0.5, 0.1)), max_t = 4, model = "cr")
phy <- tr$tes
# A coarse search without the survival GAM
ab <- auto_bounds(phy, model = "cr", n_test = 3L, bisect_steps = 3L,
                  train_surv_gam = FALSE, verbose = FALSE)
ab$lower_bound
ab$upper_bound

# The default search, which also trains the survival GAM (see train_GAM()
# for why a fit should not be conditioned on it)
ab2 <- auto_bounds(phy, model = "cr", verbose = FALSE)
predict_survival(ab2$survival_gam, as.data.frame(t(ab2$center)))

compare_models Compare fitted models by AIC, carrying the Monte Carlo handicap

Description

Ranks two or more fits from estimate_rates by AIC. Each fit's log-likelihood is a log of a Monte Carlo mean, so it sits below the log-likelihood it estimates; how far below grows as that fit's own effective sample falls, and the amounts do not cancel between models. A model that is harder to sample is therefore penalised for being harder to sample, and the AIC difference between two fits can be smaller than the difference in their biases.

Usage

compare_models(..., margin = 2)

Arguments

...

Two or more emphasis_fit objects. Names become the row labels; unnamed arguments are labelled from the fitted model.

margin

AIC units within which two models are not told apart. Default 2.

Details

The returned table carries ESS and loglik_gap per fit and AIC_swing, twice the gap relative to the leader's, which is how much of the AIC difference the bias alone could account for.

ranking_at_risk names the models that could overtake the leader once both biases are corrected. A model qualifies only if its own gap is larger than the leader's — so that correcting both closes the distance — and then either the swing reaches its delta_AIC or its draw is heavy enough that the swing understates the gap. A warning is issued with it.

Two things follow that a caller should not have to infer. The attribute is about the ORDER, not about precision: when the leader is itself the heavily-handicapped fit, correcting the biases only widens its lead, so nothing is named and nothing is wrong with that. And it covers bias, not variance. A fit can lead on a log-likelihood estimated from a handful of effective draws — measured: a winner with an effective sample of 6.5 of 300 — and be named by nothing here, because its expected position is safe while its realised one is noisy. loglik_se and ESS are the columns for that, and they are in the table to be read.

The row with the lowest AIC is not the model the table chooses. Among nested models the richer one has the lower AIC whenever its two extra parameters raise the log-likelihood by more than 2, which they do on a share of trees generated without them: with two extra parameters the likelihood-ratio statistic is chi-squared on two degrees of freedom under the null, so the richer model takes the minimum on about 13% of null trees, and with three richer models offered beside the null, on more. Measured, on 20 trees a cell from a diversity-dependent generator at 50 to 200 tips: a lineage-level model had the minimum AIC on 2 to 7 of 20, and led by more than 2 AIC on 0 to 2 of 20 (E27). The chosen attribute is therefore the model with the fewest parameters among those within margin AIC units of the minimum, the one with the lower AIC when several share that number of parameters, and within_margin marks those rows; the full ranking is kept so that the margin can be read.

A warning names the chosen model when its own effective sample is below 10 draws: its log-likelihood is then an estimate from a handful of histories and the margin it rests on is noise as much as evidence. The ranking_at_risk attribute covers the bias of unequal precision; this covers its variance.

Value

A data frame, one row per fit, with columns model, n_pars, loglik, AIC, loglik_se, ESS, loglik_gap, gap_heavy, delta_AIC, AICw, AIC_swing and within_margin, ordered by AIC, with attributes chosen (the most parsimonious model within margin of the minimum), chosen_starved (whether that model's effective sample is below 10) and ranking_at_risk.

Examples

set.seed(1)
tr  <- simulate_tree(pars = log(c(0.5, 0.1)), max_t = 4, model = "cr")
phy <- tr$tes
ctrl <- list(max_iter = 5, num_trees = 30)
fit_cr <- estimate_rates(phy, method = "mcem", model = "cr",
  control = c(ctrl, list(lower_bound = c(-3, -5), upper_bound = c(1, 0))))
fit_dd <- estimate_rates(phy, method = "mcem", model = "dd",
  control = c(ctrl, list(lower_bound = c(-3, -0.1, -5, -0.1),
                         upper_bound = c(1, 0.1, 0, 0.1))))
compare_models(cr = fit_cr, dd = fit_dd)

covariate_path Selection along a path over the covariates

Description

Instead of comparing nested models one pair at a time, this traces the differential-geometric LARS path of Augugliaro, Mineo and Wit (2013) over all the covariates a rate can read — N, D and ED — on the same augmented trees an M-step maximises over. Under the exponential link the complete-data log-likelihood is a log-linear point process: one row per lineage and segment between consecutive events, with N, D and K at their values on the segment (each is constant between events), ED at the segment's midpoint, the segment's length as exposure, and a count of one when that lineage's own event ends the segment. The speciation and extinction halves separate, so each rate gets its own path.

Usage

covariate_path(
  trees,
  log_weights = NULL,
  n_trees = 40L,
  covariates = c("N", "D", "ED"),
  rate = c("speciation", "extinction"),
  criterion = c("BIC", "AIC"),
  n_gamma = 60L
)

Arguments

trees

A list of augmented-tree data frames with the topology, as augment_trees returns them with parent ids, or a single phylo taken as fully observed.

log_weights

Optional log importance weights, one per tree; without them every tree weighs the same.

n_trees

How many trees to use: the n_trees of largest weight (the first n_trees without weights), renormalised.

covariates

Which covariates to offer the path; any of "N", "D", "ED", "EDc" (ED centred on the alive lineages), "K" (the number of speciation events on the path from the crown).

rate

"speciation", "extinction" or both.

criterion

"BIC" or "AIC" along the path.

n_gamma

Number of points on the path.

Details

The path is the curve on which the Rao score statistics of the active covariates are equal in size and the inactive ones smaller, \(|r_j(\beta)| = \gamma\) for \(j\) active, traced from the \(\gamma\) at which the first covariate enters down to zero, with the intercept always free. It is solved here on a grid of \(\gamma\) by Newton steps rather than by dglars's predictor–corrector, because the point process needs a true exposure offset, which that package does not take; on a constant-exposure problem the two agree (tests/testthat/test-lineage-table.R). The order of entry says which covariates the data ask for first; AIC and BIC along the path pick a point, with BIC's sample size the number of events.

Importance weights enter the likelihood as row weights, one per tree and normalised to sum to one, so the objective is the expected complete-data log-likelihood of one tree — the M-step's Q function — and the sample size behind BIC is the weighted mean number of events per tree.

Value

A list with one element per rate: the path (a data frame with one row per \(\gamma\): the coefficients, the log-likelihood, the active set size, AIC and BIC), the entry order of the covariates (the \(\gamma\) at which each enters), the coefficients and active set at the criterion's optimum, and the frame's size. A rate with no event in the trees (the extinction rate of a fully observed tree) gets an empty path: path is NULL, active and entry_order are empty and n_events is 0.

Examples

set.seed(1)
tr  <- simulate_tree(pars = log(c(0.5, 0.1)), max_t = 4, model = "cr")
phy <- tr$tes
cp <- covariate_path(phy, rate = "speciation")
cp$speciation$entry_order

diagnose_cem Diagnostics for a CEM fit

Description

Computes convergence, importance-sampling quality, and population-diversity diagnostics from the output of emphasis_cem or estimate_rates (method "cem").

Usage

diagnose_cem(
  x,
  plot = TRUE,
  lower_bound = NULL,
  upper_bound = NULL,
  true_pars = NULL
)

Arguments

x

An emphasis_fit object (from estimate_rates with method = "cem") or the raw list from emphasis_cem.

plot

Logical; if TRUE (default), produce diagnostic plots.

lower_bound, upper_bound

Optional numeric vectors of the same length as the parameter vector. When provided, dashed horizontal lines are drawn at the lower (orange) and upper (purple) bounds in each parameter-trace panel, making it easy to see whether the estimate has converged away from the boundary.

true_pars

Optional named or unnamed numeric vector of true parameter values. Useful in simulation studies where the generative parameters are known. When provided, a red dashed line is added to each parameter-trace panel at the true value. In real-data analyses this argument should be omitted (the true parameters are unknown).

Details

The function works on the details component of an emphasis_fit object or directly on the list returned by emphasis_cem. It requires that the fit was produced with the current version of the package (which stores history, final_pop, and best_IS in the output).

Convergence ($convergence)

A data frame with one row per iteration containing:

iteration

Iteration index.

best_loglik

IS log-likelihood of the best particle.

n_valid

Number of particles with a finite fhat.

rej_lambda

Trees rejected due to max_lambda exceedance.

rej_overruns

Trees rejected due to max_missing exceedance.

Population spread ($population_spread)

Per-iteration summary of the fhat distribution across all valid particles: median, interquartile range, and total range. A narrowing range indicates population convergence.

IS quality ($IS_quality)

Importance-sampling diagnostics computed from the final evaluation of the globally best parameter vector (with max(sample_size, n_boot, 1) augmented trees):

ESS

Effective sample size: \((\sum w_i)^2 / \sum w_i^2\).

ESS_fraction

ESS as a fraction of n_trees.

mean_lw, sd_lw

Mean and SD of IS log-weights.

fhat

IS log-likelihood estimate.

n_trees, n_rejected

Trees simulated and rejected.

Final population ($final_pop)

The full particle population at the last completed iteration (before resampling), with columns for parameters and fhat per particle. Useful for inspecting the distribution of surviving particles.

Raw IS data ($best_IS)

The raw IS output for the best particle: logf, log_q, lw (log-weights), and trees (augmented tree data frames in C++ format).

Value

A list of class "cem_diagnostics" (invisibly) with components convergence, population_spread, IS_quality, final_pop, and best_IS.

Examples

set.seed(1)

                 max_iter = 5, num_particles = 20))

                     true_pars = log(c(0.5, 0.1)))
diag$convergence

emphasis_pipeline Full estimation pipeline: auto_bounds -> GAM -> CEM -> MCEM

Description

Runs a multi-stage estimation workflow with automatic bounds detection, exploratory fits (GAM and CEM), and optional MCEM refinement. Each stage is timed and logged. If MCEM fails, the best exploratory result is returned.

Usage

emphasis_pipeline(
  tree,
  model = "cr",
  link = "exponential",
  stages = c("bounds", "gam", "cem", "mcem"),
  control = list(),
  verbose = TRUE
)

Arguments

tree

A phylo object, branching-time vector, or simulate_tree result.

model

Model specification: "cr", "dd", "d", "nd", "ed", "ned", "k", "nk", a formula (e.g. ~ N + D, ~ N + ED, ~ N + K), or a binary vector.

link

Link function: "exponential" (default), rate = exp(eta), under which the intercepts beta_0 and gamma_0 are log rates; "linear", rate = max(0, eta), under which the parameters are rates and a covariate can drive a rate to zero, where it is clipped.

stages

Character vector of stages to run. Default c("bounds", "gam", "cem", "mcem"). Remove stages to skip them, e.g. c("bounds", "gam") for a quick exploratory fit.

control

Named list with optional sub-lists bounds, gam, cem, mcem to override defaults for each stage. Common parameters (num_threads, default 1, max_missing, max_time, rho) can be set at the top level and are inherited by all stages. rho, the sampling fraction in (0, 1], is inherited by the bounds, gam, cem and mcem stages alike, and a value nested under control$gam, control$cem or control$mcem overrides the inherited one for that stage.

verbose

Logical. If TRUE (default), print progress and a summary log to the console.

Stages

  1. Bounds: auto_bounds detects parameter bounds and trains a survival GAM, which the later stages condition on. The GAM is not accurate enough for that (experiment E43; see train_GAM). To condition on another survival probability, or not at all, leave this stage out and give control$lower_bound, control$upper_bound and, to condition, control$survival_gam in any form estimate_rates(cond = ) accepts.

  2. GAM: Fits a smooth likelihood surface over a grid and optimises it. Fast, one-shot.

  3. CEM: Cross-entropy global search. Stochastic, no init needed. Explores the space differently than GAM.

  4. MCEM: Monte Carlo EM starting from the best init found in stages 2–3. Local refinement for precise estimates.

Value

A list of class "emphasis_pipeline" with:

pars

Named parameter vector from the best stage.

loglik

Log-likelihood from the best stage.

AIC

AIC from the best stage.

best_stage

Which stage produced the final result.

rho

The sampling fraction the best stage ran at.

log

Data frame with one row per stage: stage name, pars, loglik, AIC, elapsed seconds, status, rho.

mcem_trace

If MCEM ran, a data frame of per-iteration fhat and parameter values. NULL otherwise.

bounds

The auto_bounds result (bounds + survival GAM).

fits

Named list of individual emphasis_fit objects.

Examples

set.seed(1)
tr  <- simulate_tree(pars = log(c(0.5, 0.1)), max_t = 4, model = "cr")
phy <- tr$tes
# CEM stage only, with the search box given (log rates: the
# exponential link is the default)
res <- emphasis_pipeline(phy, model = "cr", stages = "cem",
  control = list(lower_bound = c(-3, -5), upper_bound = c(1, 0),
                 cem = list(max_iter = 3, num_particles = 10)),
  verbose = FALSE)
res

# Bounds found automatically, then CEM
res2 <- emphasis_pipeline(phy, model = "cr", stages = c("bounds", "cem"),
  control = list(cem = list(max_iter = 3, num_particles = 10)),
  verbose = FALSE)
res2$log

estimate_rates Estimate diversification rates from a phylogenetic tree

Description

Unified entry point for parameter inference under the general diversification model. Accepts a simulated or empirical tree, extracts branching times (pruning to extant tips if needed), and dispatches to the chosen optimisation back-end.

Usage

estimate_rates(
  tree,
  method = c("mcem", "cem", "gam"),
  model = "cr",
  init_pars = NULL,
  control = list(),
  link = "exponential",
  cond = NULL
)

Arguments

tree

One of:

  • a phylo object (extant tips only recommended),

  • the list returned by simulate_tree ($tes is used automatically, falling back to a pruned $tas), or

  • a numeric vector of branching times (crown-age ordering).

The covariate D is a lineage's pendant age – measured from the last time that lineage became a tip – centred on the mean over the alive lineages, so it is a function of the topology and not of the branching times alone. A phylo (or a simulate_tree result) carries it; a bare numeric vector does not, and every observed lineage is then recorded as dating from the crown, which leaves D = 0 at every observed branching event. Fit "d" or "nd" from a tree, not from branching times.

method

Optimisation method:

"mcem"

Monte Carlo Expectation-Maximisation (default). Iterates E- and M-steps until parameters stabilise (max relative change < tol for patience consecutive iterations) or max_iter is reached. Requires init_pars.

"cem"

Monte Carlo Cross-Entropy Method. Initialises a particle population randomly within the bounds and evolves it until convergence (annealing exhausted, plateau, or control$max_iter reached). Does not need init_pars.

"gam"

GAM-based MLE. Evaluates the IS log-likelihood on a grid spanning the bounds, fits a smooth GAM surface, and optimises it via L-BFGS-B. One-shot (non-iterative); no init_pars needed. Requires the mgcv package.

model

Model specification. Accepts:

  • a formula such as ~ N, ~ N + D, ~ N + ED or ~ N + K,

  • a string shortcut ("cr", "dd", "d", "nd", "ed", "ned", "edc", "nedc", "k", "nk"), or

  • an integer vector c(use_N, use_M, use_D, use_ED, use_K) (use_M is internal only and should be 0; a shorter vector is an earlier layout and is padded; use_ED = 3 selects the centred covariate).

model = "all" fits the nested ladder cr, dd, nd, ned, nk (the last two need a phylo), each started from the estimate of the model it nests, with each model's box from auto_bounds unless control$bounds names one per model, and returns the fits with their compare_models table and its chosen model, the fewest parameters within 2 AIC of the minimum (an emphasis_fits object); control$models restricts the ladder. Default "cr" (constant rate). "nd" (~ N + D) is diversity and age-imbalance; "ned" (~ N + ED) diversity and evolutionary distinctiveness, which needs a phylo. "nedc" (~ N + EDc) reads ED minus its mean over the lineages alive at the same time, a covariate with clade mean zero, so that beta_ED carries only the within-clade contrast and none of the clade-level level that N tracks. "nk" (~ N + K) is diversity and the number of speciation events on the path from the crown to the lineage, hidden splits counted; it needs a phylo and runs on the thinning sampler.

init_pars

Starting parameter vector. Required for "mcem"; ignored for "cem". If NULL with "mcem", the midpoint of the bounds is used, with covariate slopes started at 0 (linear link) so that lambda stays positive during the early E-steps.

control

Named list of tuning parameters. Must include lower_bound and upper_bound. Use estimate_rates_control to inspect other defaults. Key entries:

lower_bound

Numeric vector of lower parameter bounds. Length must be 2 + 2*sum(model). Order: c(beta_0, [beta_N], [beta_D], gamma_0, [gamma_N], [gamma_D]) (D = age-imbalance covariate; M is internal only).

upper_bound

Numeric vector of upper parameter bounds (same order).

verbose

Print progress messages. Default FALSE.

link

Link function: "exponential" (default), rate = exp(eta), under which the intercepts beta_0 and gamma_0 are log rates; "linear", rate = max(0, eta), under which the parameters are rates and a covariate can drive a rate to zero, where it is clipped.

cond

The survival probability to condition on, or NULL (default) for no conditioning. When provided, the log-likelihood is conditioned: \(\ell_{\rm cond} = \ell - \log P_\theta(S)\), where \(P_\theta(S)\) is the probability that both crown lineages leave a sampled descendant at the present. Three forms are accepted: a function of the parameter data frame that returns \(P_\theta(S)\) (the probability, not its log), a GAM from train_GAM, or a nnet object (see predict_survival). The GAM is not accurate enough to condition on; the section ‘Conditioning on survival’ says what to pass instead.

Conditioning on survival

The survival emulator of train_GAM is not adequate for any lineage-level model. In experiment E43 (https://franciscorichter.github.io/emphasis/experiments/E43.html), GAMs trained on 2000, 5000 and 20 000 simulated clades for each of d, nd, ed, edc, ned, nedc, k and nk had a 90th-percentile error of \(\log P(S)\) of 0.44 to 2.56, against the 0.05 its adequacy rule required, and the error did not fall with the training size.

Under cr and dd, condition on the exact survival probability. The package does not export a function for it: pass one to cond. The function receives a data frame with one row per parameter point and columns named as the parameters (beta_0, gamma_0 under cr), and returns \(P_\theta(S)\), one value per row. Under constant rates on the exponential link, with \(\lambda = e^{\beta_0}\), \(\mu = e^{\gamma_0}\), \(d = \lambda - \mu\), crown age \(T\) and sampling fraction \(\rho\), one crown lineage leaves a sampled descendant at the present with probability

\[p = \frac{\rho d}{\rho\lambda + (\lambda(1-\rho) - \mu)e^{-dT}}\]

(\(p = \rho / (1 + \rho\lambda T)\) when \(\lambda = \mu\)); the two crown lineages are independent, so \(P_\theta(S) = p^2\). The last example below codes it. Under dd the exact value solves the master equation of the clade size, which the package does not provide. E43's Monte Carlo reference agreed with the exact values to a median error of 0.007 (cr) and 0.008 (dd) in \(\log P\).

Under a lineage-level model, either fit without conditioning or pass a function that returns a direct Monte Carlo estimate of \(P_\theta(S)\) at each row: the share of single forward draws from simulate_tree (max_tries = 1) in which both crown lineages leave a sampled descendant, a clade that reaches the lineage cap counted as surviving (at \(\rho = 1\), the share with status "done" or "too_large"). At a standard error of 0.01 in \(\log P\), one such estimate took E43 a median of 2 to 29 seconds of one core, depending on the model, and the M-step evaluates cond at every parameter value it tries.

Value

A list with class "emphasis_fit" containing:

pars

Named numeric vector of parameter estimates.

loglik

Final log-likelihood estimate. For MCEM this is the importance-sampling estimate at the returned parameters, and is NA when the E-step evaluating them failed.

loglik_var

Bootstrap variance of loglik due to Monte Carlo noise. Populated automatically when control$num_trees >= 2 (B = 200 replicates); NA when num_trees = 1.

n_pars

Number of free parameters (used for AIC): parameters with lower_bound == upper_bound are fixed and not counted.

AIC

Akaike Information Criterion: -2 * loglik + 2 * n_pars.

method

Method used ("mcem" or "cem").

model

Resolved binary model vector.

rho

The sampling fraction the fit was computed at, after the control merge.

stop_reason

Why the MCEM run stopped ("converged", "max_iter", "time_budget", "e_step_failure", "m_step_failure"); NA for other methods.

iterations

Number of completed MCEM iterations (0 when every E-step failed); NA for other methods.

n_failed

Number of E- or M-step failures over the MCEM run; NA for other methods.

notes

Named character vector of what the measurements and the run say about this fit: size, starved and turnover (emitted as a warning or messages when the fit is made), mean_field (the surrogate proposal's mean-field iteration was relaxed below the full step, ran under a damping other than "auto", or did not converge within its sweep budget: the setting, the sweeps taken, the relaxation and residual of the last E-step, and how many E-steps of the run relaxed or failed to converge) and clock (max_time ran out inside an E-step or an M-step). print() shows the last two.

details

# Conditioning a cr fit on its exact survival probability, P(S) = p^2
cond_cr <- function(T, rho = 1) function(pars) {
  lambda <- exp(pars$beta_0)
  mu     <- exp(pars$gamma_0)
  d      <- lambda - mu
  p <- ifelse(abs(d) < 1e-12, rho / (1 + rho * lambda * T),
              rho * d / (rho * lambda + (lambda * (1 - rho) - mu) * exp(-d * T)))
  p^2
}
crown_age <- max(ape::branching.times(phy))
fit_cond <- estimate_rates(phy, method = "mcem", model = "cr",
  cond = cond_cr(T = crown_age),
  control = list(lower_bound = c(-3, -5), upper_bound = c(1, 0),
                 max_iter = 10, num_trees = 50))

simulate_tree Simulate a phylogenetic tree under the general diversification model

Description

Unified entry point for forward and conditional tree simulation. When tree = NULL (default) a complete tree is simulated forward from the crown; when tree is supplied the observed extant tree is augmented with stochastically drawn extinct lineages.

  tree = NULL,
  pars,
  max_t = 1,
  model = "cr",

Optional observed extant tree for augmentation. Accepts NULL (forward sim), a simulate_tree result, a phylo object, or a numeric branching-time vector. Numeric parameter vector or matrix. When a matrix each row produces one forward simulation.

Model specification (string, formula, or binary vector). Default "cr".

Maximum lineages alive before declaring the tree too large; a clade that has had ten times as many lineages in all, alive and dead, is too large as well, which bounds the cost of a simulation that churns (high speciation and extinction over a long crown) under the cap. Default 1e6.

Maximum number of forward simulations in all, the first included (forward simulation only): a clade that goes extinct is drawn again until one survives or max_tries draws have been made, so the default 1 is a single draw, unconditioned on survival. Convert L-table to phylo via DDD. Default TRUE.

Number of augmented trees to draw (augmentation only). Default 1L.

Link function: "exponential" (default), rate = exp(eta), under which the intercepts beta_0 and gamma_0 are log rates; "linear", rate = max(0, eta), under which the parameters are rates and a covariate can drive a rate to zero, where it is clipped.

max_missing

Maximum extinct lineages per augmented tree. Default 1e4.

max_lambda

Maximum speciation rate (thinning bound) for augmentation. Default 500.

Maximum total augmentation attempts. NULL (default) sets this to max(2000, 200 * n_trees).

Threads for parallel augmentation. Default 1L.

Sampling fraction in (0, 1]. Default 1 (complete sampling). With rho < 1 a random fraction of extant tips is dropped (forward simulation) or unsampled extant lineages are inserted (augmentation), matching incomplete taxon sampling.

method

Augmentation method: "bdi" (default, exact BDI sampler) or "thinning" (C++ thinning proposal). The BDI sampler draws from the exact conditional distribution under constant rates (ESS = S, zero variance) and uses a self-consistent backward-forward iteration under diversity dependence. It covers N-only models ("cr", "dd") on the linear and exponential links; any other model or link falls back to thinning.

method = "bdi" returns NULL for part of its draws. The BDI sampler has no notion of the two crown lineages, so a lineage born before the first observed branching is recorded as a daughter of observed node 0, which is not yet born then. Such a draw cannot be turned into a tas: it is refused, and that element of trees (or tas, with n_trees = 1) is NULL. On seven trees measured for this release, 0 to 168 of 200 draws built; a tree whose first observed branching is late loses most of them. log_q is returned for every draw either way. It was previously silent and wrong – every such draw produced a phylo with an edge of negative length. The "thinning" method draws the parent from every lineage alive, the two crown lineages included, and is not affected.

Model specification

The model's covariates are diversity N, age-imbalance D = E - M (a lineage's isolation relative to the clade mean M, which is used only internally to centre D) and evolutionary distinctiveness ED (the fair-proportion score on the complete tree: the branches from the crown to the lineage, each divided by the alive lineages below it; its last term is the pendant age and its sum over lineages is Faith's phylogenetic diversity). Selected by named shortcuts or a formula:

"cr" constant rate
"dd" diversity dependence (N)
"d" age-imbalance (D)
"nd" N + D
"ed" evolutionary distinctiveness (ED)
"ned" N + ED
"edc" centred ED (ED minus its mean over the lineages alive)
"nedc" N + centred ED
"k" ancestral splits (K: the speciation events on the path from the crown)
"nk" N + K

Formulas ~ N, ~ N + D, ~ N + ED, ~ N + EDc and ~ N + K are also accepted (ep is a legacy alias for d). An ED or K model needs the tree's topology (a phylo, not a branching-time vector).

Parameter vector

Compact layout; beta_D is the age-imbalance coefficient and beta_ED the distinctiveness coefficient (M is internal only, never part of the user vector): 

c(beta_0,  [beta_N],  [beta_D],  [beta_ED],
  gamma_0, [gamma_N], [gamma_D], [gamma_ED])

Only active covariates are included; length = 2 + 2 * sum(model).

Reproducibility

Every call draws its seed for the C++ sampler from R's generator, so set.seed() fixes both the forward simulator and the thinning augmenter: two runs under one seed return the same tree, two runs under different seeds do not. The retries a forward simulation makes draw a seed each, so they are distinct trees rather than one tree redrawn. Under parallel::mclapply each child has its own R stream and therefore its own seeds. Augmentation with num_threads > 1 is not reproducible: each worker draws from its own substream of the seed, but the sample keeps the first n_trees augmentations to finish.

train_GAM Train a survival-probability GAM on forward simulation results

Description

Fits a binomial GAM to estimate P(survival | parameters) from forward simulations run with max_tries = 1 (one draw each, unconditioned on survival). Each simulation row has a binary outcome: 1 if both crown lineages reached the present (status "done") or the clade passed the lineage cap ("too_large"), 0 if it went extinct. A clade stopped at the cap has survived so far, and the conditional likelihood divides by the probability of survival; counting it as extinct teaches the GAM a survival near zero wherever clades grow fast, which then rewards the fit for moving there (E36c of the paper).

.augment_tree_bdi BDI augmentation: draw sample_size augmented trees.

Description

Returns the same structure as the augment_trees() C++ function, list(trees, logf, logg, weights, fhat), plus the draw counts.

Usage

.augment_tree_bdi(
  tree,
  pars,
  model_bin = c(0L, 0L, 0L),
  sample_size = 1L,
  max_missing = 10000,
  link = 0L,
  rho = 1,
  use_gaussian_closure = TRUE,
  topology = NULL,
  mesh = NULL,
  attach = c("rate", "uniform"),
  damping = "auto",
  deadline = Inf
)

Details

Draws are attempted until sample_size have completed or the budget of 5 * sample_size attempts is spent. A draw is rejected when its missing-lineage count exceeds max_missing (counted in n_rejected_max_missing) or, under DD, when a missing lineage is still alive at the present (counted in n_rejected; such a tree has f = 0 at rho = 1). Completed draws with a non-finite log-weight are dropped from the returned tree set (the M-step set) but stay in the fhat denominator with weight zero.

fhat = log(sum_w / n_valid) + max_lw + log(acc), where n_valid counts every completed draw and acc = n_valid / (n_valid + n_rejected) is the acceptance rate of the survivor channel. max_missing overflows are excluded from the denominator, as in the thinning E-step (S_completed in src/E_step.cpp).

The log(acc) correction is derived at rho = 1, where a surviving missing lineage has f = 0 and the rejection is a property of the target. At rho < 1 an unsampled survivor is a legitimate configuration and is emitted rather than rejected, so n_rejected is 0, acc is 1 and the factor is inert. acc is the stop-at-n_valid plug-in estimate of the acceptance rate, which is biased at small sample_size: at the function's own default sample_size = 1L a draw with three survivor rejections moves fhat by log(1/4) = -1.39. At the MCEM default of a few hundred draws the bias is of order 1e-3.

Every pre-first-split lineage is attached to observed node 0

.bdi_to_tree_df records, as the parent of an augmented lineage born at t, the last observed branching at or before t (max(which(bt_sorted <= birth) - 1L)). For a lineage born before the first observed branching there is none, and the expression falls back to observed node 0 – a lineage that is not yet born at t. The sampler has no notion of the two crown lineages, which is where such a birth really attaches, and it never records the reserved crown ids the thinning sampler uses.

The consequence used to be silent and wrong: tas carried an edge of negative length wherever it happened. On seven trees measured here, the parent build turned all 200 draws into a phylo and 5 to 200 of them had a negative edge, the shortest -7.15.

.aug_to_Ltable now refuses an attachment older than its recorded parent and returns NULL, so those draws produce no tree at all. The failure is loud where it used to be silent, and the throughput is the price: on the same seven trees, simulate_tree(method = "bdi") built 0, 106, 124, 129, 153, 156 and 168 trees out of 200, with the refused draws in every case exactly those carrying a lineage born before the first observed branching. A tree whose first observed branching is late loses most of its draws; one whose crown splits early loses few.

.bdi_integral_cr Exact integral of total BDI rate over [t1, t2] for CR with constant n, k.

Description

total_rate(t) = (n+2k)*lam0*(1-p(t)) + n*mu0/(1-p(t))

Usage

.bdi_integral_cr(t1, t2, n, k, lam0, mu0, tp, rho = 1)

Details

Uses the identities: int lam0*(1-p) dt = mu0*(t2-t1) + ln[p(t1)/p(t2)] int mu0/(1-p) dt = lam0*(t2-t1) + ln[(1-p(t1))/(1-p(t2))]

Valid on both sides of lam0 = mu0. Both log-ratios are evaluated with s = |lam0 - mu0| in the exponent, so the argument of exp is never positive and the mu0 > lam0 side does not overflow; writing the factors as s - r*expm1(-s*tau) also removes the cancellation of lam0 - mu0*E near lam0 = mu0.

Under incomplete sampling the same two identities hold with p replaced by its rho-sampled counterpart – they follow from dp/dt = lam*p^2 - (lam-mu)*p alone, which carries no terminal condition – so only the closed forms of the two log-ratios change. With

A(t) = d*E + rho*lam0*(1 - E) (so p = rho*d/A) B(t) = A(t) - rho*d (so 1 - p = B/A)

and E = exp(-d*(tp - t)), the integrals are

int lam0*(1-p) dt = min(lam0,mu0)*(t2-t1) + ln[A(t2)/A(t1)] int mu0/(1-p) dt = max(lam0,mu0)*(t2-t1) + ln[B(t1)/B(t2)]

At rho = 1, B(tp) = 0 and the second integral diverges as t2 -> tp: a doomed lineage must die before the present. At rho < 1, B(tp) = d*(1-rho) is non-zero and the integral is finite – a doomed lineage may survive to the present as an unsampled extant tip, which is the configuration .bdi_augment_one then has to emit.

Value

The integral value (Inf when rho = 1, n > 0 and t2 == tp).

.bdi_integral_cr_rho The rho < 1 branch of .bdi_integral_cr.

Description

Kept in its own function so that the complete-sampling path is the code the validation study measured, byte for byte.

Usage

.bdi_integral_cr_rho(t1, t2, n, k, lam0, mu0, tp, rho)

Details

A and B are written so that every exponential argument is non-positive and every term of every sum is non-negative, on both sides of lam0 = mu0:

d > 0: A = d*(1 + em) - rho*lam0*em, em = expm1(-d*(tp - t)) B = d*(1 - rho) + em*(d - rho*lam0) d < 0: both multiplied by exp(-s*(tp - t)), s = |d|, and negated A = s - rho*lam0*em, em = expm1(-s*(tp - t)) B = s*(1 - rho)*exp(-s*(tp-t)) + em*(s + rho*lam0) the scale factor exp(-s*(tp - t)) contributes -s*(t2 - t1) to ln[A2/A1] and +s*(t2 - t1) to ln[B1/B2], which is exactly what turns the min/max prefactors around.

B is 1 - p times A and p is in (0, 1], so B > 0 throughout for either sign of d - rho*lam0.

.bdi_supported Can the BDI sampler be used for this model/link/rho?

Description

The sampler conditions on a rate that is a function of the lineage count alone: .bdi_p_cr and .bdi_solve_p_backward solve one survival probability p(t) shared by every lineage alive at t, and the aggregate Gillespie of .bdi_augment_one moves n_alive lineages with one pair of rates. Usage

.bdi_supported(model_bin, link, rho = 1)

Arguments

Length-3 binary model vector c(use_N, use_M, use_D).

link

Integer link code: 0 linear, 1 exponential.

rho

Sampling fraction in (0, 1]. Default 1.

Details

A lineage-level model (D, model_bin[3] != 0, or ED, model_bin[4] != 0) gives each lineage its own rate, so no single p(t) is the model's. The sampler then conditions on the rate of the clade's average lineage instead: an ED of P-hat/N-hat, which the mean-field iteration solves for, and a D of zero, since D is centred. The proposal is exact for that surrogate model and the importance weights carry each lineage's departure from the average; the attachment of a birth is tilted by the parent's pendant age, where D and ED read the tree. This is available on the linear and exponential links. The M covariate (model_bin[2]) is not in scope: the sampler's own mean-field state would have to be closed on P as well as N, which is written but not gated.

The linear and exponential dd rates are monotone in N. On a 20-tip tree over a 4 x 8 x 4 grid in (beta_0, beta_N, rho) with a 200-sweep budget, the Picard iteration of .bdi_iterate reached the fixed point for both in every cell, in at most 27 iterations at rho = 1. Incomplete sampling is in scope for every model and link the gate otherwise accepts. p(t) becomes the probability of leaving a sampled descendant (.bdi_p_cr, .bdi_solve_p_backward, both of which take rho), and .bdi_to_tree_df emits the 5e10 sentinel for a missing lineage still alive at the present, so the draws carry unsampled extant lineages and N(t) counts them.

"bdi" falls back to "dynamic_fresh", with a message naming the reason, for a D- or M-dependent model.

damping

BDI only: under-relaxation of the mean-field sweep, which is a Picard iteration \(x \leftarrow F(x)\). Where its map expands the iteration diverges and a larger budget makes it worse: on a 416-tip tree at rates whose equilibrium is critical the residual is 305 after 20 sweeps and 329 after 200. A partial step, \(x \leftarrow (1-\omega)x + \omega F(x)\), contracts it. "auto" starts at \(\omega = 1\) and halves it whenever the residual grows; on that tree it converges in 40 sweeps, and where the map already contracts it is the plain iteration to the bit. A number in \((0, 1]\) fixes \(\omega\) instead; 1 is the plain iteration. "default" (the default) is "auto" at rho = 1 and \(\omega = 1/8\) at rho < 1: in experiment E10c a fixed 1/8 converged 0 of 192 units within the 20 sweeps at rho = 1 against 131 for "auto", at 1.4–3.3 times the E-step time and no gain in effective sample, and below rho = 1 it converged more (142 against 131 at rho = 0.2); an explicit "auto" or number is used as given. Relaxation below about \(1/20\) converges too slowly to be useful. It fixes the iteration and nothing else: at 416 tips the effective sample is 2.1 of 97 even with a converged mean field, because the proposal must invent some 600 missing lineages there (audit H108). Every E-step's mean field is in the trace (mf_converged, mf_delta, the final residual, mf_sweeps, mf_omega, the relaxation of the last sweep, and mf_budget); when some E-step relaxed the iteration below the full step or did not converge within its sweep budget, or the setting is not "auto", the fit's notes carry a mean_field entry with the resolved setting (and whether it is the default for the fit's rho), the sweeps, relaxation and residual of the last E-step and whether it converged, and print() shows it.

MCEM is considered converged when the largest relative parameter change, \(\max_j |\theta_k[j] - \theta_{k-1}[j]| / \max(|\theta_{k-1}[j]|, c)\), is below tol for patience consecutive iterations. The bound box does not enter. The floor \(c\) carries the units of the parameters (see .rel_floor): tol / crown_age where they are rates (linear link) and tol where they are log-rates (exponential link), so the statistic does not change when the tree is expressed in another unit of time. Default 1e-2: every coordinate must move by less than 1% of its own magnitude, patience times in a row. The step the sampler itself produces sets whether that is reachable – on a 12-tip CR tree at num_trees = 200 the statistic has median 0.02 and falls below 1e-2 in about a fifth of iterations – so runs at these defaults commonly end at max_iter. Raising num_trees shrinks the Monte Carlo part of the step.

patience

Number of consecutive iterations with parameter change below tol required to declare convergence. Default 3.

max_iter

Maximum CEM iterations (hard cap). Default 20.

num_particles

Particle population size (parameter vectors per iteration). Default 50. Alias: num_points.

sd_vec

Initial perturbation SDs. NULL (default) sets each to (upper - lower) / 4 at call time.

maxN

Max augmentation attempts per particle evaluation. Default 10.

num_trees

Augmented trees simulated per particle per iteration. Default 1. Alias: sample_size.

shared_trees

If FALSE (default), each particle is evaluated on its own simulated trees. If TRUE, trees are pooled across all particles and every particle's fhat is re-evaluated over the full pool (lower variance; bias correction not yet implemented).

disc_prop

Elite fraction retained per iteration (Cross-Entropy Method). Default 0.5.

bias_correct

Apply moment-based bias correction to the IS log-likelihood. Default FALSE.

num_trees

When > 1, bootstrap variance of the log-likelihood is computed automatically (B = 200 replicates) from the IS weights already drawn. Minimum recommendation: 5. loglik_var in the fit is NA when num_trees = 1.
